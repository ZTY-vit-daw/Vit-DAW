信号色语义 · 仪表灯规则
蓝 · 活动
播放头 / 状态控件「进行中」/ 激活宏档位 / 发送钮 / 磁带舱灯（工程就绪）。暗场上取 --blue-lt 保证 4.5:1 以上可读。
黄 · 注意
峰值偏热轨道（吊镲 右）/ 削波预警卡。只在出现真实风险时点亮，不做装饰。
红 · 录制
transport 录制臂与总线表顶部段。本组图未进入录制态，红灯仅在 DAW 层驻留待命。
灯语规则：信号灯直径 8px，外圈以纸色细环替位发光；同一时刻至多一盏主灯；信号色仅作小面积高精度使用，不做大面积铺色、不做霓虹外发光。宏卡强度条为分段 LED，只表「多少」、不标数值——宏影响不暴露原始参数。
