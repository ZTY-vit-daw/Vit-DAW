# Vit 对话流主窗口 v3 · 三方向设计 spec（2026-11-13）

## 1. 产品与任务

Vit 是 AI-first DAW：对话窗（Ask Vit）不是侧边附件，而是**软件的主窗口**。本次大重设计把 2026-11-09 v2 终选版（`../launcher-route-mondrian-v2.png`）的"对话窗"从启动页组件升格为全局主窗口，并定义它跨三态的连续叙事。用户要求：**大重设计、更有产品感，不是小修小改**；保留 Mondrian 令牌与磁带 icon 两个锚点，在其语境内的诠释可以大胆。

三态定义（新形态，与 v2 的核心差异）：

- **态A 启动台**（无工程）：对话窗为主体（大、居中或主导位），磁带工程列表为可展开抽屉（磁带卡+把手），背景=启动页。对话流含开场白+快捷 chips+输入槽。
- **态B 进入中**（过渡）：用户手动点击工程 → **icon 待机动画→进行中动画**；agent 启动 → 对话流内出现**状态控件**（待机→进行中）。关键：DAW GUI 不做页面切换，而是**从对话窗背后升起、展开、沉到对话窗之后**（Z 轴叙事，非 v2 的整屏切换）。对话窗全程可见，输入暂歇。
- **态C 工程内**：DAW GUI 沉于对话窗后方（背景层，可暗化/景深处理表达主次），对话窗收缩为**主窗位**（不再是 v2 的 442px 小浮卡——要有主导感，建议占画面 34–50% 宽或全高主面板），磁带抽屉收拢为边缘把手；对话窗内渲染工程上下文对话流＋控件卡。另需画出**收起态**小样：对话窗缩为侧边把手条（用户编辑 DAW 时的让位机制）。

## 2. 必画元素清单（每版都要有，缺一不合格）

1. **三态联版**：态A / 态B / 态C 三屏并排（每屏 1440×900，联版总宽 ≈4400，同 v2 结构便于对比）。
2. **沉后展开过渡分镜**：在态B 屏内或联版下方画出 3–4 帧关键帧（对话窗满幅→GUI 从后方升起→GUI 落位沉后→对话窗收缩至主窗位），标注 Z 层与缓动意图。
3. **icon 三态动画分镜**：磁带 icon 的 待机 / 进行中（带轮旋转或走带指示）/ 完成 三帧横排，出现在态B；agent 启动路径画一个**对话流内状态控件**实例（待机→进行中→完成）。
4. **磁带抽屉收拢态**：态C 里磁带抽屉收为边缘把手（保留手动新建/打开工程入口）。
5. **效果器宏控件**（宏快照语义，本次新增控件）：态C 对话窗内一张宏卡——宏名（如"温暖 / 明亮 / 紧实"三档）、当前激活高亮、宏影响用**音乐性语言**呈现（不暴露原始参数数值），体现"一钮多参"的宏感。样式须与本方向语言一致。
6. 态C 的 DAW 背景至少含：轨道列表/时间线（可简化）、transport 条——足够表达"沉后"层次即可，不必复刻 v2 的全部细节。

## 3. 资产（三版共用，不得更改）

令牌（磁带色板 v2）：`--ink:#090B0E --paper:#F6F4EC --warm:#FBF9F1 --canvas:#E8E4D7 --blue:#065BC7 --blue-lt:#73B8F5 --red:#DB1214 --yellow:#FACC1A --dark:#14181C`，等宽 `Consolas`，正文 `Inter + Microsoft YaHei`。

磁带 icon（TapeIconArt 逐字复刻，SVG 等价——直接复制进你的 HTML `<script>`，可改尺寸不可改结构）：

```js
var INK="#090B0E",WIN="#FBF9F1",HUB="#FAFAF2",ACC="#1A1A1F",TINT="#E6E6E6";
function tapeSVG(w,h,a){ // a=atmos 可为 null（默认灰壳满盘）
  var bx=2,by=2,bw=w-4,bh=h-4;
  var wx=bx+8,wy=by+8,ww=bw-16,wh=bh-26;
  var cy=wy+wh/2,c1x=wx+ww*0.28,c2x=wx+ww*0.72;
  var r=Math.min(wh*0.3,22);
  var d1=a?r*(0.34+0.5*a.L):r, d2=a?r*(0.34+0.5*a.R):r;
  var labelY=by+bh-12;
  var bodyFill=a?rgba(a.c1,0.62):TINT;
  var s='<svg width="'+w+'" height="'+h+'" viewBox="0 0 '+w+" "+h+'">';
  s+='<rect x="'+bx+'" y="'+by+'" width="'+bw+'" height="'+bh+'" fill="'+bodyFill+'"/>';
  s+='<rect x="'+bx+'" y="'+by+'" width="'+bw+'" height="'+bh+'" fill="none" stroke="'+INK+'" stroke-width="2"/>';
  s+='<rect x="'+wx+'" y="'+wy+'" width="'+ww+'" height="'+wh+'" fill="'+WIN+'"/>';
  s+='<rect x="'+wx+'" y="'+wy+'" width="'+ww+'" height="'+wh+'" fill="none" stroke="'+INK+'" stroke-width="2"/>';
  [[c1x,d1],[c2x,d2]].forEach(function(reel){
    s+='<circle cx="'+reel[0]+'" cy="'+cy+'" r="'+reel[1]+'" fill="'+ACC+'"/>';
    s+='<circle cx="'+reel[0]+'" cy="'+cy+'" r="'+(r*0.32)+'" fill="'+HUB+'"/>';
    s+='<circle cx="'+reel[0]+'" cy="'+cy+'" r="'+r+'" fill="none" stroke="'+INK+'" stroke-width="2"/>';
  });
  s+='<line x1="'+(bx+10)+'" y1="'+labelY+'" x2="'+(bx+bw-10)+'" y2="'+labelY+'" stroke="'+INK+'" stroke-width="2"/>';
  s+='<line x1="'+(bx+10)+'" y1="'+(labelY+6)+'" x2="'+(bx+bw*0.55)+'" y2="'+(labelY+6)+'" stroke="rgba(31,36,43,0.6)" stroke-width="1"/>';
  return s+"</svg>";
}
// 气 atmosphere：工程名 FNV-1a 哈希→色对（v2 移植；需要时可用，非必需）
```

示例工程名沿用 v2：《小星星乐局》《ProQ3 裸控实验》《鼓组混音 v2》。

## 4. 输出格式

- 单文件 HTML（内嵌全部 CSS/JS，零外部图片、零 CDN 依赖；Google Fonts 可省，用系统字体栈），body 尺寸 ≈4400×1050（三屏联版）。
- 文件写到本目录，命名 `direction-X-<slug>.html`。
- 不需要你截图——主管统一截图。但 HTML 必须保证 Playwright 1440 视口下三屏并排完整可截。

## 5. 硬约束

1. **令牌与磁带 icon 结构不可动**（这是用户 11-09 亲定锚点）；本方向的自由度在形态语言、构图、材质、字型气质、层的表达。
2. 可读性底线：正文 ≥14px、标签 ≥12px、正文对比度 ≥4.5:1；留白必须是构图不是缺席。
3. 三版布局骨架必须互异（对话窗在态C 的位置/形态、抽屉形态、过渡分镜的构图至少一项结构性不同）。
4. 反 AI slop：不用紫渐变/emoji 图标/圆角卡+左彩条组合/SVG 画人脸；每个元素 earn its place。
5. 文案全中文、真实内容（工程名/宏名/对话），不用 Lorem、不用"标题文字"占位。
6. 这是静态高保真样图（动画用分镜帧表达），不要求 JS 动画，但 icon 三态分镜要能读出动画意图（如带轮角度变化、进度弧）。

## 6. 效果器宏控件定义（设计输入）

语义＝**宏快照**（非自由参数控制）：一个宏=一组预绑定参数的命名快照。教学语言优先。控件最低内容：宏名列表（≥3 个，示例："温暖""明亮""紧实"）、当前激活态、一个宏影响的抽象可视化（如色带/轮廓/强度条的隐喻，不显示 dB 数值）、应用动作。放置于态C 对话窗内，作为对话流中的一张卡（模型可组合调用的控件实例）。
