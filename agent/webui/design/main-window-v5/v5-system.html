S6　改动历史网格实验

《百老汇爬梯舞》的节奏进入事件排列，网格线保持中性。

第二轮 / 2026-11-14

A　单行时间带

每一段对应一次改动，宽度表示持续时间，颜色表示该事件的关注等级。

优点：最接近真实历史组件。代价：需要时间与筛选交互，不能仅靠几何块承担记录。

B　中性网格上的事件

浅灰正交网格承载少量事件，保留音乐节奏的联想。

优点：节奏鲜明。代价：网格本身不增加当前对话任务的信息，容易变成装饰。

C　按对象分行

将事件按轨道或总线分行，对比多对象上的连续改动。

优点：有跨对象观察价值。代价：密度大，需要独立历史入口与真实数据。

评估结论 / 待裁定

推荐保留 A 作为未来“改动历史”的候选；B、C 暂不进入主窗口。P3 已有快照与执行轨迹，当前加入历史条会重复表达。本轮三案都留在规格板，不进入产品屏。
