# 全局 Agent 调度规则（用户级，所有项目生效）

> 详细版与调度中枢：`C:\Users\timoz\.zcode\workspace\default\AGENTS.md`；任务队列：同目录 `queue\`。
> 本文件每个会话都会加载，保持精简——它同时是稳定上下文前缀，利于缓存命中。

## 资源与路由（速查）

- **GLM-5.3（ZCode）**：决策 + L1 引导 + L2 硬核开发（核心架构、复杂算法、安全关键、下游失败过的任务）。12000 积分/日，上限是约束不是目标。非高峰窗口 9–12、18–24。
- **GLM-5.3 flash**（ZCode，2026-08-27 起）：廉价量产引擎，性能高于 DeepSeek V4 flash；与非高峰窗口同步（9–12、18–24）。**窗口内量产任务优先派它**（经"复制提示词到 flash 会话"工作流，GLM 无法自建会话选模型）；窗口外回落 DeepSeek。
- **DeepSeek V4 flash**（≈GLM-5.2，本地 shell 可跑 PS）：flash 窗口外的量产引擎（工作日 18 点后与周末），兼批量首审。
- **Codex GPT-5.6**（桌面端，可跑 PS）：无人时段量产引擎。能力下降须加缰绳：单卡 ≤1 小时 / ≤5 文件 + 验收命令关口。
- **Claude Opus 5**：疑难攻坚（**非 PS**）+ 无人时段副决策（仅可逆决策，记 decision-log）。**Sonnet 5**：批量相似修改（非 PS）。
- **闲时任务**：免费车道，闲时排队执行确定性长任务；每日创建上限以端内为准；执行中不要往会话发消息（会转计费）。
- **PowerShell 边界**：GLM、codex、deepseek 可跑；claude 禁入（无法运行验证）。

## 节奏

进度驱动 + 任务池排序制（v4.3）：todo 是有序池，日计划只定首轮领取、不是当日边界；单卡完成≠当日完成，窗口内继续从池中取下一张，不设每日卡数目标；todo 随时保有 ≥2 张可执行余卡（可并行 2 个执行会话，须不同文件域）。窗口 9–12、18–24 按需使用；12:00 与 22:40 前提示用户是否继续，不拿数量额度当停止条件。标准日 / 轻量日 / 休息日任选，休息日系统完全静默。
早窗开始输入 `/morning`（同时校准池排序），晚窗开发开始输入 `/night`，当日收尾输入 `/gate`（三个命令在任何项目会话里都可用，操作的是中枢 queue）。发卡看里程碑，不看引擎饥饿。

## 任务流

`queue\`（todo→doing→done/blocked）是跨时段协作的胶水；任务卡模板、粒度、验收级联见详细版 §4 §5。
GLM 参与深度：L0 写卡即走 / L1 引导到可放手（默认档）/ L2 亲自开发；同一任务下游失败一次，深度升一级。

## 纪律

一任务一会话；探索用搜索工具、少 spawn 子 agent；review 看 diff 不看全文件；长文件交 deepseek 出摘要；当日消耗达 9000 积分 → GLM 降为 L0 纯决策。
