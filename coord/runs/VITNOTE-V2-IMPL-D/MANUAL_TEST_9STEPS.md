## 九步清单（按序执行；每步给结论 过/不过+现象）

### 第 1 步 · 圈选触发
**操作**：在时间线**空白区**（无 clip 处）按住 Q + 左键拖出一个矩形，松开。
**判据**：
- 拖拽过程中：屏幕出现**暗幕遮罩+亮框**（框内区域镂空清晰可见）。
- 松开后：胶囊出现在框**右侧**，文案含 `[N]`（形如「[N] 打开便签 · 圈选 N 面」；空白处圈选则为「…空辖区」）。

### 第 2 步 · 双出口
**操作**：先按 **N** 开出便签 A；再圈一次，这次**点击胶囊本体**开出便签 B；第三次圈选后，**趁胶囊还在（8 秒淡出内）**点入便签 B 的输入框（文本输入态）按 N。
**判据**：
- 两出口（[N] 快捷键 / 点击胶囊）都开出 note 面板。
- 文本输入焦点态下按 N **不**新开便签（焦点守卫生效；胶囊淡出后 N 无效是正常超时路径，非本判据）。

### 第 3 步 · 跨面合并（本卡实现的主验收面）
**操作**：从时间线起手，Q+左拖横跨**时间线+机架+资料库**三面（可先打开资料库左侧抽屉使三面同屏），松开 → 开便签。
**判据**：
- **单 note**（一场圈选至多一胶囊一 note）。
- 面板头部摘要一行=「**轨道时间线 x% · 机架 y% · 资料库 z%**」式（降序、整数百分比；机架面 label 形如「机架·<轨名>」；被截断时 hover 标题可见全行）。← **本卡 _rebuild_summary 多面版**
- 发送辖区问答后 agent 回复**只引用域对象**（轨名/clip/插件/条目名等），不出现 GUI 内部引用——payload 纯 id/值（键级核验可由执行侧 grep agent 日志补充）。

### 第 4 步 · 控制面快照
**操作**：Q+左拖圈住**走带条+2~3 个轨道头**区域，开便签。
**判据**：
- 摘要含「**控制面 x%**」（时间线轨头区域通常并入时间线面占比，正常）。
- 向便签问「这一块的 BPM 和播放位置」→ 回复引用**当前真实值**（BPM/播放位置/循环区/相交轨参数）。
- **未相交**的轨道不出现在回复引用中。

### 第 5 步 · 空辖区
**操作**：Q+左拖圈住界面**空白角**（无供给器区：四类面之外），开便签。
**判据**：
- 面板头部摘要=「note_N · **空辖区**」。
- 空辖区 note **可发**问题且 **7878 有回复**（agent 链路通）。

### 第 6 步 · 取消路径（三子案，逐一做）
**操作/判据**：
1. 拖拽中按 **ESC** → 无胶囊无 note 无残留遮罩。
2. 拖拽中**松开 Q**（仍按住左键）→ 同上。
3. Q+**单击**（不过拖拽阈值）松开 → 无任何副作用（无胶囊无 note 无遮罩无选区残留）。

### 第 7 步 · 共存边界（时间线编辑零回归——INPUT-FIX 修复面的回归验收）
**操作/判据**：
1. 普通左拖空 lane → 仍是 **clip 框选**（原 marquee 行为）。
2. **Alt+左拖** clip 体 → 仍是**克隆**。
3. **Q+左拖** clip 体上 → 发起**圈选**（D1 迁键后新行为，不再被「有 clip 让位」拦截）。
4. 时间线既有编辑（选/移/裁/画）**零回归**（随手做两三个确认）。

### 第 8 步 · 面板三态 + 修复验证（INPUT-FIX 主判据）
**操作**：开一个便签 → 输入框**打中文**（IME：切中文输入法打几个字）→ 发送一条辖区问题 → 点**收起** → 点锚点小点**重开** → 拖 **⠿ 把手**移动面板；再开第二个便签与第一个**并存**。
**判据**：
- **含收起按钮在内全部鼠标交互有效**（收起/重开/拖动/输入/发送都能点动——INPUT-FIX 修复的「面板鼠标链灭」不再复现）。
- IME 中文输入正常（组字窗不飘、上屏正常）。
- 辖区上下文进回复：agent **答的是域对象**（引用圈到的轨/clip/插件），不是泛泛而谈。
- 双 note 并存互不干扰。

### 第 9 步 · 三卡同场销收口（裁定 8）
**操作**：回顾本场 1–8 步结果，复核两张条件卡的条件项：
- **VITNOTE-IMPL-1 条件项**（M8 最小闭环的 V2 交互版=本场步骤 1/2/8）：圈选→胶囊→便签→IME→观察问答→收回→重开 全链走通？
- **VITNOTE-DOCK-MOUNT-1 条件项**：本场**全程在 dock 工作区**进行，便签层默认入口挂载可见（面板/胶囊/锚点都出得来）？
**判据**：1–8 全过 → 两张条件卡销项；任何一步不过 → 记录现象，卡按停止条件处置。
