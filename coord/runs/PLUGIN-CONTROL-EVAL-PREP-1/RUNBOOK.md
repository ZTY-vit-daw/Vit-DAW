# RUNBOOK：PLUGIN-CONTROL-EVAL 首轮（S0→P→A*→B*→C）执行手册（PREP 冻结草案）

- 依据：`plan.json`（同目录）+ [preflight](../../reports/2026-11-07-plugin-control-model-evaluation-preflight.md)。主管三裁定遵守：S1 付费/真栈不随 PREP 卡授权；test-only 缝挂「答辩前不落实」由用户拍板；**分段 P→A→B→C，组间 go/no-go**。
- 臂名说明：未经披露缝（preflight §3 锚点 S1-S4）前，A/B 为**污染臂 A\*/B\***（内核回复语义字段+提示词引导在场）；本文按污染臂出预算。纯 A/B 待缝卡落地后另批，预算结构相同、另立 run 前缀。

## 1. 分段与 go/no-go

| 段 | 内容 | LLM | 放行条件（前段完成+主管 go） | 段末检查点 |
|---|---|---|---|---|
| S0 | 夹具准备+已知操作验证（T1-T6 逐案目标可达/枚举解释/回读恢复/T4 联动允许集/T6 不可满足复核） | 0 | 真栈窗口获批+PC-RUNTIME-STACK 登记成功 | 全案 exit 0 或诚实 blocked 证据→冻结最终案例与允许变化集合 |
| P | 产品基线 6 轮（6 案例×1） | 是 | S0 全绿+付费批准 | 链路边界定位报告；不判能力 |
| A\* | 原始抓手 18 轮（6×3） | 是 | P 段收口+预算余量核 | 对照 B\*/C 前的原始下界数据完整 |
| B\* | 原始+检索 18 轮 | 是 | A\* 段收口 | 检索可用性/失败分类面完整 |
| C | 检索+语义适配 18 轮 | 是 | B\* 段收口 | 三臂配对比较数据完整 |

- go/no-go 由主管执行；任一 checkpoint 判 no-go 即停，剩余段不启动，不因沉没成本续跑。
- 组间止损示例：S0 某案两连败同签名→该案换实例重冻结或剔除（正负对照配比随之调整并记录）；A\* 段出现系统性 entry_or_authority_blocked（入口缝缺失所致）→ 停段交主管（缝决策），不计为模型失败。

## 2. 每轮定义与预算

- **一轮** = 一次任务开始→预算内操作与修正→终态。轮内多次 LLM 调用/工具调用/检索均计费计数；轮内重试不拆新轮。首次提案与最终结果都保留。
- 每轮上限（超限即停轮记 `model_budget_exhausted`）：

| 项 | 上限 | 依据 |
|---|---|---|
| LLM 调用 | 12 次/轮 | 遥测典型 1 entry+2-4 loop；上限≈2-3× 余量 |
| 单调用输入 | 40k tokens | 遥测 max 30.1k+余量 |
| 单调用输出 | 8k tokens | 遥测 max 6.8k+余量 |
| 工具调用 | 30 次/轮 | 大参数面分页（Timeless 类 1011 参数未入首轮，上限宽松） |
| 检索 search/fetch（B\*/C） | 6/10 次每轮 | 与 C 对齐同额 |
| 轮墙钟 | 20 分钟 | 遥测单调用秒级+工具往返；防挂死 |

- 段预算上限（token 计，货币换算 pending）：

| 段 | 轮次 | LLM 调用上限 | 输入 tokens 上限 | 输出 tokens 上限 |
|---|---|---|---|---|
| P | 6 | 72 | 2,880,000 | 576,000 |
| A\* | 18 | 216 | 8,640,000 | 1,728,000 |
| B\* | 18 | 216 | 8,640,000 | 1,728,000 |
| C | 18 | 216 | 8,640,000 | 1,728,000 |
| **S1 合计** | **60** | **720** | **28,800,000** | **5,760,000** |

- 期望值（非上限）：中位口径 ≈4 调用×15k 输入/轮 → 全程 ≈3.6M 输入 tokens；上表为天花板授权，不是目标。
- **货币换算缺项与校准建议**：DeepSeek 现行价目未核验（PREP 不联网）。批准付费轮时，主管应以官方价目页快照换算段预算货币上限；或先批 3 轮**校准小样本**（排除于正式成绩）实测每轮费用后再放全段。**本 RUNBOOK 不授予无限预算。**
- 计费账户：用户 DeepSeek API 账户（被测模型 deepseek-flash）。供应商前缀缓存命中按 cache_read 单独记录与计费。

## 3. 隔离与公平性

- 每轮新 conversation_id；跨轮学习性缓存清零；同案例三臂同一初始工程/插件状态/素材（独立工作副本，绝不写 sealed/样例/用户工程）。
- 输入与关键 fixture 每轮前后核对哈希；异常即停该批。
- B\*/C 检索预算同额；检索记录：query、URL、访问时间、返回片段哈希、入上下文长度（方案 §5）。
- 评价器正确参数/目标状态/允许变化集合不入被测模型上下文。
- 组序按主管裁定固定 P→A\*→B\*→C（牺牲轮换抗序性，换取组间 go/no-go 与预算分段）；缓解=轮级全新会话+冻结夹具+记录的随机化种子备用于主管批准的交错变体。
- 真栈占用：PC-RUNTIME-STACK 登记→≤60s 复核→启栈→TEARDOWN_ALL_ZERO 亲核释放；同段内独占，与他栈腿（B3/D1D3/KERNEL-OFFRENDER/VSTI-PARAM-PROBE）错峰。

## 4. 失败分类与退出码语义（逐层）

- 失败分类枚举见 plan.json `failure_taxonomy`（含 environment_interruption 需原始日志/退出证据才可排除；harness_invalid 单列夹具/评价器/组别泄露无效轮）。
- 退出码分层语义（RUNNER 卡实现时落死）：

| 层 | exit 0 含义 | 非 0 含义 |
|---|---|---|
| S0 夹具/已知操作 | 全案目标可达验证过 | 任案不可达→blocked 证据（不进模型轮） |
| 单模型轮 runner | **评估完整**（有 verdict，含失败 verdict） | 驱动/栈/夹具异常（harness_invalid，不是模型成绩） |
| 段批 runner | 段内全部计划轮已评估（含模型失败） | 预算/止损/污染触发停止，剩余轮报未运行 |
| 整 S1 | 60 轮全评估 | 任何段间 no-go 或全局停止 |

- **exit 0 ≠ 任务成功 ≠ 产品验收**；每轮另有模型任务 verdict（JSON）。脚本退出码不得吞掉 verdict 面。
- 里程碑报告必须分列：链路进度 / 模型任务成绩 / 实验有效性 / 产品验收边界。

## 5. 工件与可回指性

- 每段每轮：run_id、时间、HEAD、工作树基线、完整命令与各层退出码、二进制哈希（-SkipBuild 时必附）；每轮结果表字段=plan §12（case_id/arm/repeat/actual_model/entry_status/first_action/final_verdict/failure_tags/readback_artifact/mutation_count/search_count/input_tokens/output_tokens/cached_tokens/cost/pending/stop_reason；cost 缺失显式标 missing）。
- agent 原始日志+遥测副本（独立 run 目录，不用工作区共享遥测文件判读——该文件混有测试噪声）；检索来源片段；参数面前后快照。
- 证据落独立 worktree/port 分支，新目录不覆盖旧 run；不污染主检出。

## 6. 跑前批准清单（缺一不跑）

1. 主管放行对应段（组间 go/no-go 记录）。
2. 付费预算批准：token 上限已确认+货币换算已核（价目快照或校准样本）。
3. 真栈窗口：PC-RUNTIME-STACK 空闲登记成功。
4. 被测模型面：启动 shell 三组环境变量记录（VIT_AGENT_LLM_*/OPENAI_* 是否覆盖 `~/.vit/config.json`）；首轮请求捕获核验响应 model/采样参数（preflight §1 待验项）。
5. P 臂确认卡应答策略冻结（RUNNER 卡定）。
6. 案例终冻结：S0 全绿后的最终目标值/容差/允许变化集合版本化（hash 入 run 工件）。

## 7. 已知边界（诚实声明）

- A\*/B\* 为污染臂（污染范围见 preflight §2/§3）；其成绩是**下界**解释，不得表述为纯原始能力。
- 一次 60 轮 pilot 只证可行性摸底；同案例 3 重复≠3 独立插件样本；不据此宣称稳定性或删减适配栈。
- 本 RUNBOOK 冻结于零运行勘察；所有 `[待新运行验证]` 项在首轮执行时核验并回填，发现与静态证据冲突时以运行证据上报主管修订，不静默改口径。
