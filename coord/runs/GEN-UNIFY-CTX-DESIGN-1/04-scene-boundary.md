# 设计件四：场景边界（工程内生产强制携带 / 自由创作豁免）

- 归属：GEN-UNIFY-CTX-DESIGN-1 / 2026-10-11
- 卡面要求：工程内生产=强制携带；自由创作/艺术家自主场景=豁免机制（预答辩创作实验直接消费此边界）。

## 1. 场景枚举（scene，生成调用级参数）

| scene | 语义 | 自动块注入 | 机检门 |
|---|---|---|---|
| `in_project`（**默认**） | 工程内生产：生成产物落工程内（写轨/入媒体池/进渲染链） | **强制**（快照全量渲染，消费方不可跳过） | **强制**（件三矩阵按产物形态执行） |
| `free_creation` | 自由创作/艺术家自主：工程外或实验环境内的自主创作 | **不注入**（快照仍组装但 MUSIC CONTEXT/CONSTRAINTS 块整体省略——调用记录留快照供审计，提示词不留自动块） | 不启用 |
| `experiment_control` | 工程内**对照实验臂**：产物在工程内生成但作为实验对照（自动块"关"臂） | 不注入（同上） | 不启用（对照臂产物按实验协议标注，不入正式生产验收） |

- scene 是**每次生成调用的显式参数**（快照字段之一，件一 §4），默认 `in_project`——**不设全局开关、不落工程级持久化字段**。理由：①"工程内生产强制携带"是用户裁定，默认即强制，任何偏离必须显式且留痕（调用记录逐次可审计）；②全局开关/工程字段会把"某次豁免"泄漏成"此后都豁免"，破坏统一性默认。
- 三枚举而非两枚的原因：论文合规率实验（2026-09-29-thesis-positioning-decision.md:16："生成物 tempo/调性/拍号 vs 工程参数，**提示词面板开/关对照**"）需要工程内的"关"臂——`experiment_control` 把实验对照与生产豁免分开，防止实验流量伪装成自由创作（或反之）；两臂产物打不同 scene 标记，实验数据可按标记分组统计。
- 豁免的**不可叠加**纪律：`free_creation`/`experiment_control` 下消费方不得自行拼装任何工程音乐特征进提示词（旁路注入）——豁免是"零自动上下文"不是"自定义上下文"。ARTIST-AUDITION 的"仪器通道"（投影读数）属于**实验环境包自带素材**，不经生成面注入，不违反本纪律（环境包=冻结工件，由实验主持侧组装，与生产生成链分离）。

## 2. 预答辩创作实验的消费映射（ARTIST-AUDITION-1 直接消费）

ARTIST-AUDITION-1（coord/cards/todo/2026-10-10-ARTIST-AUDITION-1.md，用户 2026-10-11 早窗裁定后置至生成线首批+编曲前置就绪）的设计原则与本边界的咬合：

| 实验原则（卡面原文语义） | 本边界提供 |
|---|---|
| 风格零指令（"风格指令过删除检验=任务非世界"） | `free_creation` 零注入——style_note 等一切工程字段不进入提示词 |
| 环境可能性空间塑造（乐器配置/未完成物调性/文本物气质三杠杆） | 杠杆素材在**环境包**（实验主持侧冻结工件），不经生成面——边界把"世界"与"任务"在生产机制上隔离 |
| 同一环境被给予而非同一世界被感知 | 注入面缺席=各模型感知差异不受工程上下文对齐力影响（实验变量纯净性） |
| 磁带机按响才有降质 loop（行动通道） | 工程能力面（回听/试奏）照常可用——豁免只关"注入"，不关"工具" |

即：实验解冻后，其生成调用全量走 `scene:"free_creation"`，本边界即其机制底座；实验工件（环境包版本/问句原文）由实验卡自带，本设计不代管。

## 3. 边界判定的工程语义（什么算"工程内生产"）

- 判据=**产物落点**，不是调用入口：产物将写入工程（轨道 clip/媒体池 asset/渲染 job 输入）→ in_project 义务链生效。凡走 `add_midi_notes*`/`apply_midi_note_patch`/`insert_midi_clip`/`import_midi_to_track`/`assets.ingest_generated_asset` 落工程面的写命令，其前置生成调用**必须** scene=in_project（豁免 scene 下发这些命令=契约违规，编排器层拒绝——写前门兼哨兵）。
- 工程外产物（实验工件目录、协调 run 目录、纯文本歌词交付）不受此限——`free_creation` 的合法产物面。
- `experiment_control` 的产物落工程时（对照需要同工程上下文）**允许**落轨，但产物 clip 命名/asset 元数据带 `experiment_control` 标记（实现归消费卡；统计期按标记剔除生产口径）。

## 4. 混音 v2 消费者注记

混音为 v2 可选消费者（设计前提①）。届时其取用面=快照只读消费（不产 MIDI，无机检义务），scene 语义不变——本边界设计对 v2 消费者前向兼容（消费不改变场景义务，义务只拴产物写入）。
