## 3. 逐门裁定

### 3.1 逐轨 RMS 地板：−45 → −100（保留形式，放宽值）

- **保留形式的理由**：逐轨"非数字死轨"是材料类型无关的真实约束——一条精确数字静音的 stem（全零，RMS≈−240）无论合成或真实材料都属不合格材料（agent 可选中该轨、渲染恒平、观察面退化）。
- **−100 的推导**：pv1 实测合格材料最安静轨 −90.7；PCM16 量化底 −96.1（20·log10(1/32768)）；地板 −100 同时低于两者（距最安静真实轨 9.3 dB 裕量，距量化底 3.9 dB），拒绝数字静音（−240）与低于 −100 的空轨。不取 −96：钉在量化底语义上、对 −90.7 级真实轨裕量仅 5.3 dB；不取 −120：对真实安静轨无额外保护意义（量化噪声级内容由对比门族拒绝，见 §4 反例 C）。

### 3.2 逐轨 crest 地板：10 → 6（保留形式，放宽值）

- **保留形式的理由**：削波/方波化损伤是**逐轨**属性，必须逐轨拦截（反例 B 的确定拒因）。
- **6 的推导**：实测最低 8.62（p03 bass，真实密集低音）；地板 6 留 2.6 dB 裕量；重度削波材料（样本方波化 ≥~20%，crest ≤~5.7）被拒。**诚实边界（削波增益实测扫描）**：轻中度削波不被此地板拒——p05 guitar +24 dB 增益削波后 crest 9.0（5.6% 样本削波）、+30 dB 后 6.5（17%）；地板 6 的判别线落在 ~+32…34 dB（19–22% 样本削波、crest 6.1→5.7）之间。残余风险（crest 6–8 的过度压限轨未被材料前置门拒）由 best crest（集级）与实验六字段判据（被测对象侧）承担，不在材料前置门职责内。

### 3.3 best crest 地板：14（不变）

- pv1 每例 best crest 19.334–31.765，全部以 ≥5.3 dB 裕量通过——集级"存在压缩可作用的动态余量"是材料类型无关约束，spv1 口径已覆盖 pv1，不动。

### 3.4 逐轨 sibilance 地板：撤销（None）

- 实测 2.12–42.70：**真实 stem 合法地不含时局域化高频事件**（bass、近静音轨 2.12–5.17）。要容纳它们的逐轨地板须 ≤2，对任意真实信号（≥~2）形同虚设——**撤销而非虚设**。
- 先例：现行 stereo-balance 门（FAM3-S2）即因"逐轨形式对近 mono 材料虚设"而采用纯 best 形式（代码注释明载）；本裁定沿用同一推理模式。

### 3.5 best sibilance 地板：14 → 6

- pv1 每例 best 9.767–42.696（最低 p03 9.767）；地板 6 留 3.8 dB 裕量。仍拒绝高频能量全程平坦的材料集（平稳噪声 ~0–3、静音 0，见 §4 反例 C）。

### 3.6 逐轨瞬态地板：撤销（None）

- 实测 3.56–58.55：持续型真实轨（p03 bass 3.56、p06 vocals 4.78、p07 vocals 5.90——p06 的原拒因即此）合法存在；容纳它们的逐轨地板须 ≤3，虚设——撤销。同 §3.4 先例。

### 3.7 best 瞬态地板：14（不变）

- pv1 每例 best 43.945–58.548，裕量 ≥30 dB；拒绝平稳材料集（噪声 ~2–3）。不动。

## 4. 反例区分度（门不形同虚设）

三组反例（构造于本目录 `counterexamples/`，不触材料仓），全部须被 pv1 profile **拒绝**（`verify_profiles.py` 实测，见 `counterexample_results.json`）：

| 反例 | 构造 | 预期拒因 |
|---|---|---|
| A 数字静音轨 | pv1_p05 真例，guitar 换为全零 PCM16 | 逐轨 RMS（−240 ≤ −100）+ 逐轨 crest（0 < 6） |
| B 削波轨 | pv1_p05 真例，guitar +48 dB 后 ±1.0 硬削波（~36% 样本方波化，crest ≈4.1） | 逐轨 crest（< 6） |
| C 平稳噪声集 | 六轨全换 −20 dBFS 白噪声 | best sibilance（实测 0.51 < 6）+ best 瞬态（< 14） |

## 5. 作用域与兼容语义（实现面）

- manifest 顶层声明 `qualification_profile`（本卡枚举：`spv1_synthetic` | `pv1_real_stems`）；**未声明 = 默认 spv1 口径，零行为变化**（向后兼容，现存所有清单/调用不变）。
- 声明了未知 profile 名 → runner **fail closed**（ValueError），不静默回落（AGENTS §11 未知枚举策略）。
- 报告 `material_qualification` 新增 `qualification_profile` 字段与生效门值回显（None=该 profile 不设此逐轨门）。
- flavor 作用域门（pan/limiter/gate/multiband 子门）两 profile 下均维持 spv1 校准参数不动（PILOT=neutral 不触发；见顶部纪律边界）。

## 6. 验证矩阵（verify_profiles.py，实现后运行）

1. pv1 七例（声明 pv1_real_stems）→ 全 PASS；
2. spv1 九例（未声明 → 默认）→ 全 PASS（作用域化零破坏回归）；
3. 反例 A/B/C → 全 REJECT 且拒因符合 §4 预期；
4. 未知 profile 名 → fail closed。
