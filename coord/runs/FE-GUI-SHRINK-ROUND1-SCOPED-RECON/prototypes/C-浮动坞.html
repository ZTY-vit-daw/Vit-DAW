方向 C · 浮动坞（iPad dock 气质）

你的「浮动窗口」灵感的另一诠释：不需要进入任何切换态——右缘常驻一条视图坞，点图标即以可拖拽的浮动卡片窗唤出该视图（带弹性出场动画），浮窗可 ⚓ 吸附进右槽变回固定栏，也可 ⇱ 再弹出；「收纳」一键让所有浮窗回坞。主基座（音轨＋机架）永远不动。

交互动线（本稿可点）

  • 点右缘坞「卷帘 / 混音 / 详情」→ 浮窗弹出（可多开，注意克制）
  • 拖浮窗标题栏 → 任意摆放；⚓ → 吸附进右槽（机架回坞）
  • 右槽「弹出 ⇱」→ 把当前右槽内容弹回浮窗态
  • 坞底「⇤ 收纳」→ 全部浮窗一键回坞；底栏「标注」看标注

    • 关键假设（讨论点）

  • 浮窗=「策展的卡片」：尺寸/层级受控，不追求任意分割——与自由分割树的边界在此
  • 右槽同一时刻只吸附一个视图；音轨永不被覆盖为槽位
  • 视图坞常驻右缘（对照 A 的 F2 切换态：C 无模式、A 有模式）

    • Godot 落地口径

  • 视图坞=EdgeActivityBar 垂直窄柄形态扩展，确定可实现
  • 浮窗拖拽/弹性动画=Control+Tween，确定可实现
  • 「浮窗↔吸附」状态同步=需适配（中等工程量：槽位宿主与浮窗层交换父子关系）
