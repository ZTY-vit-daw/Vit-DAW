## 十轮裁定要点（浓缩，详见各稿「设计说明」与 index 收敛注记）

1. 收缩方向：iOS/GPT 式归拢，废弃自由分割树（茅草屋）；多开=浮卡/真窗口双档
2. 需求出发（移动端）：移动=云端/远程客户端；对话流=agent GUI 载体（webui），PC 对话=外置窗
3. 手机端必要集：时间标尺（磁带化走带线）→固定推子（竖）→带录制走带（磁带机式，录音键最醒目）；其余全交对话流组件
4. 平板端=先仿库乐队/音悦家做像+唯一更新点=底部浮动输入框
5. PC=四位台前自动铺排（1/2/3/4 位语法+LRU 挤出）+左列陈列调度+抽屉坞
6. Master 置顶第一轨；横便于阅读、竖便于操作（竖屏）
7. **图样设计未来优先按原始资产延展**（vit_mondrian_theme.gd / vit_ui_assets.gd / vit_ui_button_styles.gd / themes/vit_popup_safe_theme.tres）；本轮定的是布局
