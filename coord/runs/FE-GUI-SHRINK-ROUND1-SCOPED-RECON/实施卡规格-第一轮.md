## 卡 1（主卡）：PC 端四位台前调度布局改造（Godot）

### 目标

PC 端主工作区从「自由分割树多视口」改为「**四位台前自动铺排**」：最多 4 个台前位，自动铺排语法 **1=全屏 / 2=左右 / 3=左整+右上下 / 4=田字**；默认两位=音轨+机架；满员再推=挤出最久未动（LRU）。配套：F2 台前调度面板、视图抽屉坞、浮卡/真窗口双档多开、Master 置顶、agent 对话保持外置窗。

### 布局规格（自上而下）

| 区 | 规格 | 原型锚 |
|---|---|---|
| 菜单栏 | 文件/编辑/视图/工程/帮助 + 右侧 HUD（采样率/缓冲/CPU 只读）——由 AppHeaderShell 收敛而来 | V11 `#menubar` |
| 走带工具栏 | **现役 Top_Transport_Bar 原样保留**（LCD 竖栈：主时间/子时间+BPM·TAP·拍号/按钮行 ⏮⏹⏵⏺🔁+停→0；右区 VitCore 读出条 I/O·DSP·AI + Local Node + 🤖 AI 助手(C)），仅新增两个按钮位：`⊞ 视窗 F2`、`保存` | V11 `#toolbar`（已逐节点对齐 tscn） |
| 主区 | 左：资料库（left_library_dock **原样**，⋮ 柄开合）＋ 中：**台前四位网格**（slot-grid 引擎）＋ 顶部：视图抽屉坞（收起=小柄，落下=积木条） | V11 `#slot-grid` `#view-drawer` |
| 底部状态栏 | 台前位况（N 位 · 视图名）+ 快捷键提示 + 「agent 对话=窗外独立窗口」注记 | V11 `#statusbar` |

### 交互规格（入口清单）

1. **F2 / ⊞ 视窗** → 台前调度面板：左侧台后积木卡列（层叠陈列+动效，台前中黄标）；中前=前台铺排小卡（镜像当前 1-4 位形状）；卡上「推上台前」（进空位/满四挤出 LRU）/「⊞ 浮窗」；拖卡入指定位。
2. **▦ 视图抽屉**（顶部柄，从上落下）：积木 chip——**拖到工作区某视窗=装入该位**；**点击=开浮窗多开**；与 F2 共用数据源；用后收起。
3. **槽位头**：位号标签 + 「✕ 拉下」（该位清空，剩余视图自动重排铺排形状）。
4. **双击 MIDI 片段** = 钢琴卷帘推入音轨所在位（音轨回台后架）。
5. **多开双档**：浮卡（可拖拽，⚠ ↗ 弹真系统窗口=Godot Window 节点；旧 detached_viewport_window.gd 仅作参考，其多视口归因妥协不继承）。
6. **🤖 AI 助手 (C)** = 现役 chat_toggle_requested 语义（外置 webui 窗），不改。
7. 拖拽实现口径：**指针式自绘拖拽**（按下→幽灵卡跟随→落点检测装载），不用 HTML5 式浏览器拖拽协议。

### 退役清单（收缩目标）

viewport_split_tree_builder 自由分割、视口标题栏 7 视图切换菜单、水平/垂直分割按钮、弹出 detached 按钮（保留位语义上由真窗口双档替代）、工作区预设 tabs（default_arrange/sound_design/dual_screen_dual_track 不再上 UI）、New Window 按钮、右缘常驻视图坞（→抽屉）。workspace_layout_manager/preset_repository 代码保留为数据层，不再驱动 UI。

### headless probe 断言点（复用 ps1 冒测体系，Godot headless + agent HTTP/ZMQ 面断言）

1. 启动后：主区 slot 容器=2 位（音轨+机架）；**断言不存在**：预设 tabs / New Window / 视口标题栏分割·弹出按钮 / 右缘常驻坞
2. F2 注入 → 调度面板出现（台后卡数=5-台前数）；「推上台前」注入 ×2 → **4 位田字**断言（容器子数/网格形状）
3. 拉下至 1 位 → **独占全宽**断言；拉到 0 位 → 空态提示断言（不崩溃）
4. 满四再推 → **LRU 挤出**断言（默认两位预置在 LRU 队列）
5. 抽屉 chip 拖拽注入 → 指定位装载断言；chip 点击 → 浮卡实例化断言；浮卡 ↗ → 独立 Window 实例断言
6. 双击 MIDI clip 注入 → 卷帘入位断言
7. 音轨视图 **Master=第一轨**断言
8. 走带栏回归：chat_toggle_requested 唤起行为不变；**mixboard_ 请求 id 前缀不变**（红线回归，参照 M8 口径）

## 卡 2（设计基线，webui 侧后续立卡，不动 Godot）：移动端两形态

**手机端（V5）**：① 工程流首页（TikTok 式全屏工程预览：气氛动态底图[未来按原始资产延展]/中央播放/双击或↗进入/预览⟷列表双视图）；② 工程页=对话流＋底部三件套（**输入框永远最下**→磁带机走带[回退/播放/暂停/停止/**录音最醒目**/🔊弹**竖**推子]→红指针走带线[时间读数在两端]→⌃推开**浮动轨道歌单**[右手位 M/S/监听，左手可切/自动感应]）；左上 ‹ 返回；☰=工程菜单（导出/分享+设置）。原则：**竖屏只有底部是横的，其余全竖（横便于阅读，竖便于操作）**。

**平板端（V7）**：库乐队/音悦家式基座（顶走带 LCD/左轨头图标瓦片+音量条+M/S/片段画布/混音 popover 竖推子/循环库）＋唯一更新点=**底部浮动输入框**（浮于界面上方，画布穿过）＋对话流自输入框向上展开为浮动卡列；黄框=agent 处理对象标注。

- 三端对话词汇同源：状态卡/结果试听卡/A/B 盲听卡/提案步进卡/采集气泡。
- 实施平台=webui（React，agent GUI 载体）；架构假设：移动端=远程客户端（内核驻留 PC/云，音频流式回传）。
