# 决定：能力域三分法（编曲 / 混音 / 生成）

- 会话：GLM 主管决策流 / 2026-11-05（用户口头裁定）
- 关联：[2026-11-05-generation-mcp-pivot.md](2026-11-05-generation-mcp-pivot.md)（生成线转 MCP）；本决定是 2026-10-11 用户裁定"生成≠MIDI；编曲才需要 MIDI；生成需要的是生成模型的调用能力"（AIGC-DRUM-GEN-1 卡面 §状态修订）的推广定案

## 一、分界规则（用户原话意旨）

> **一切不走生成能力的、对 MIDI 进行编辑的就是编曲能力；对音频进行编辑的就是混音能力。**

| 能力域 | 操作对象 | 智能来源 | 音色/处理面 |
|---|---|---|---|
| **编曲** | MIDI（一切非 AIGC 的 MIDI 编辑手段） | LLM 符号分析→编辑 MIDI | **音源/合成器的加载、调用、调整、控制**——像混音线的效果器控制功能一样，为编曲写同构的控制能力（2026-11-05 用户定调） |
| **混音** | 音频 | 既有自由态/混音链 | 效果器控制（PCA，已建成） |
| **生成** | AIGC 素材（人声等音频） | 生成模型（Suno via MCP，套壳按 MCP 思路） | 无域内音色面 |

## 二、卡池处置

1. **AIGC-DRUM-GEN-1**：**取消结案（2026-11-05 用户裁定"鼓卡直接取消"）**——鼓=音源+MIDI 打击乐编辑归编曲域，编曲按完整任务线重新勘察（ARR-RECON-1，池序 258）；卡内实证事实仍可引用（写入/确认/回读三环现成；"挂 instrument 无 agent 通道"=音源控制缺口在卷依据）；
2. **GEN-VOCAL-SYNTH-1**：人声可能真需要（用户 2026-11-05）→ 留生成线（MCP 方向），冻结维持；
3. **FREESTATE-REGION-IMPL-1**：同日取消结案（源于对自动化实现方案的误解；包络线处理已实现）。

## 三、编曲勘察卡范围（按本分界定稿）

1. **音源控制面**（核心新能力）：混音线插件控制资产（vst3host 装载 / plugin_list_available / plugin_search / get_plugin_parameters / plugin_grabber / PCA admission·processorregistry 族）对 instrument 插件（VSTi）的适用性盘点；内核 MIDI 轨↔instrument 路由现状；装载音源到轨、选 preset、调参数的命令缺口清单与命令面草案；
2. **MIDI 编辑面盘点**：写面已亲核全；编配级批量操作缺口（整段复制/移调/声部铺排/clip 编排）；
3. **符号分析衔接**：乐局 1a 符号核命令的编曲消费路径（LLM 符号分析→编辑 MIDI 链路）；
4. **资产映射与首张实现卡建议**：混音线控制资产复用面 + 音源装载最小闭环卡面草案。
