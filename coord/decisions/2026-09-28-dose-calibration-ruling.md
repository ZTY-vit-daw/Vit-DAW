# 2026-09-28 剂量口径裁定（用户）

## 用户裁定（原话要点）

「把上限加宽，允许 agent 调控到 ±10 dB 左右，这样才能做到一次改动可以确保改到用户的可听范围。」——针对 PAPER-EXP-RECON-1 上交的剂量口径裁定点（56b/正文 ±2 dB 现口径 vs 57 §6 ±6 dB 制度），用户选择**放宽到 ±10 dB**（超出 57 §6 提案幅度，采其制度方向）；并确认"顺带统一素材量级三处数值不一致"照办。

## 裁定内容

1. **DOSE-AUDIBLE-1 按 ±10 dB 落地**：56b/正文 ±2 现口径作废；57 §6 制度采纳但幅度取 ±10 dB（用户裁定覆盖 ±6 提案数值）。声像轴随 57 §6 制度对齐 ±0.5（用户裁定只点名 dB；如需另值由决策侧再调）。
2. **落地卡**：`coord/cards/todo/2026-09-28-DOSE-AUDIBLE-1.md`（P1）。上限**单点常量化**——2026-09-28 main 亲核 ±2/±0.15 字面量散布 ≥10 处（chat 4 文件 + agentloop 2 文件 + 提示/能力文案），逐处改数字会再造漂移面。
3. **与 2026-09-26 基线冻结裁定的冲突处置**：冻结裁定"基线接受 cherry-pick 修复、不接受行为变化"——上限放宽属**行为变化**，**不自动进 `paper/experiment-baseline`**；实验基线容纳方式（重切 tag vs 记版本演进后 cherry-pick）列为 K1–K7 拍板会议题，正式 runs 前必须收口。
4. **素材量级三处不一致**（56b §2 / 57 §2.2 / dose_basis_lm.json）：并入 56b 定稿议程（随 K 拍板会）——以 sealed+正式采用的 suite 版本重出一张实测表，56b §2 随之校正。

## 追记（2026-09-28 第二次裁定：通用原则，用户澄清）

用户原话要点：「要调的！是**所有可被调整的范围**都需要被提升至'**确保能够被用户听觉感知到的阈值范围**'。」——剂量上限的设定标准是可听性原则，适用于**全部剂量轴**，不是只挑 dB；pan 不取"制度原案值"的默认理由，按同一原则定值。

**轴表（2026-09-28 main 亲核）**：

| 轴 | 现上限 | 新上限 | 可听性依据（量级） |
|---|---|---|---|
| 轨道增益 delta_db | ±2 dB | **±10 dB** | 用户裁定值；10 dB ≈ 感知响度减半/加倍 |
| 频段增益 gain_db | ±2 dB | **±10 dB** | 同族；显著改变频段掩蔽关系 |
| 压缩阈值 threshold_db | ±2 dB | **±10 dB** | 显著改变增益缩减与动态形态 |
| 声像 delta_pan | ±0.15 | **±0.5** | 线性刻度（-1..1）半幅横移，A/B 明确可辨；复听校准后如需另值再调 |
| 选频 frequency_hz / Q | 20–20000 / 0.1–18 | 维持 | 选择域（选哪里调），非幅度轴（调多少），不属剂量 |

**锚点层新发现**：剂量边界不只散布在 chat/agentloop 执行层（≥12 处），**域规格层** `internal/experiment/d1s1_domains.go` 有 16 处 "+/-2"——含 `PromptParameterHint`（LLM 直面的参数提示）与 `ValidateDoseBounds` 闭包校验及报错文案。**单点常量的家=experiment 包**（chat/agentloop 均已依赖，亲核）；执行层锚点改引常量。DOSE-AUDIBLE-1 卡面已按轴表与三层锚点更新。
