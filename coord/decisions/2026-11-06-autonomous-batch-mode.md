# 决定：单决策流自主批次模式（修订 2026-10-09 协作裁定）

- 会话：GLM 主管决策流 / 2026-11-06（用户口头裁定：试点验证通过后放权）
- 修订对象：2026-10-09 用户裁定中「用户继续触发执行与交接」条款——其余（卡池唯一、worktree 纪律、栈占用协议、逐文件 add 等）全部保留不变。

## 一、模式

用户每日启动一个主管决策流（GLM 会话），决策流内自主闭环：派发（子代理模板 flash-worker / L2-worker / 内置 Explore）→ 执行 → 自我接收 → 按证据验收 → 合入 → 推进下一张。用户不必逐卡触发；通宵运行（PC 保持开机，决策流收口到夜间安全终态，**不自主关机**——不可逆且无法确认收口完整）。

## 二、自主权分级

| 级 | 内容 | 处置 |
|---|---|---|
| L0 自主 | 池内领卡/派发/验收/合入 main（可逆）/真栈 run（§8 口径不变）/勘察/ruling/同类发卡 | 直接干，gate 披露 |
| L1 攒批 | 框架内应用级裁定、新开同类卡、止损裁量 | 照常执行+记裁定台账（gate 报告），48h 翻案窗口 |
| L2 挂起 | 翻案用户既有裁定；不可逆动作（删 worktree/分支/工件、改历史）；外发；跨能力域开线；涉用户手测义务节点；卡面前提被推翻影响主线 | 卡挂 blocked-waiting-user + 写 [PENDING-DECISIONS.md](../PENDING-DECISIONS.md)，继续跑不受影响卡；紧急（栈损/仓库风险）止损优先 |

- 预算：不设现金/积分上限（订阅制）；§8 质量纪律（跑前口径/运行次数/失败分类/止损线/单 run 无重跑）**全部保留**——止损护栏替代预算护栏。
- 夜间：允许一切 L0 面（含 LLM 真栈 run）；子代理缰绳=单卡 ≤1 小时+≤5 文件+验收命令关口（codex 先例）。

## 三、用户验收=手测里程碑制

1. 用户唯一验收渠道=**Godot 拉起 GUI 真实手测**（2026-09-12 裁定入口不变）；
2. **不是每卡手测**：卡收口时有用户可感面（UI/听感/流程）→测试项累积进「里程碑手测清单」（coord/ 手测清单文件，随 gate 维护）；无可感面的卡由决策流按 §5/§7 证据验收；
3. **里程碑触发**（M-1 混音线 / M-2 三线 / 后续追加）→ 决策流生成一次性手测包：Godot 启动步骤（同 shell 环境变量）+按序剧本+通过判据+失败分卡回溯表；用户照测通过=该里程碑前全部内容完成验收；
4. 用户保留任意抽查权（重查任何我验收过的卡，证据链必须可回指原始工件）；Milestone 级节点确认不降级。

## 四、引擎分层

flash-worker（GLM-5.3 flash）=量产腿；L2-worker（GLM-5.3 高推理）=硬核实现/取证；Explore=勘察；LLM 量产腿（ablation/话术组）可继续用子代理真栈 run 承载（订阅积分制下不再区分现金车道）。子代理执行记录 owner=「GLM 主会话+模板名」，领取协议照走（worktree/分支/领取记录/回执）。
