# 决策：判断权归属原则（防固化红线）——2026-10-30 用户裁定

## 背景（用户原话锚点）

用户 2026-10-30 手测后提出："你是不是陷入到脚本一切的固化误区中了？这点我非常担心。" 并给出实例裁定：话术提及"副歌"而工程无标记时，应由 LLM 判断思考——混音能力环节本就有打段落标记的能力，agent 应询问是否标记，而非 Go 固定问句"用开头 30 秒可以吗"。

## 事实轨迹（自证）

- 218：词表路由 LLM 前接管（验收时当优点：秒出）
- 219 面 1/2/3：澄清文案写在 Go（"用开头 30 秒可以吗"/"是从 0 开始的 N 秒吗"）——固化方向最新实例，2026-10-30 当日验收通过，同日被本裁定列为迁移候选
- 220 定案：词表 miss 变体话术 LLM 未收到路由指引（neutral 装配分支缺 embed）——LLM 判断层欠建设与确定性层扩张同时发生

## 原则（分层判断权归属）

| 归确定性层（正当） | 归 LLM（判断权，不得写死） |
|---|---|
| 意图**识别**（词表=路由/缓存，秒出省 token） | **问不问、问什么、提议什么**（澄清决策） |
| **执行**链（CAS/幂等/治理/逐点读回） | 变体话术理解与工具选择 |
| 安全兜底（LLM 不可用降级路径、权限红线、裸模式串永不授权） | 能力提议（如"要不要我先打上副歌标记"） |

一句话：**确定性层只做识别+执行+兜底；一切判断归 LLM。词表命中但信息不足时，出口是带上下文移交 LLM，不是固定问句。**

## 护栏（冻结令）

1. **判断类决策（澄清文案/问不问/提议内容）自本裁定起不再新增 Go 固定文案**；新增一律走 LLM 路径。
2. 既有固定澄清面迁移清单（225 承接）：span 降级候选问句、肯定词族引导、裸单端候选问句（219 面 1/2/3）——迁移后降级为 LLM 不可用兜底。
3. 词表保留为路由/缓存（识别意图），不得升级为判断者。
4. 本原则候选升入 AGENTS.md 长期规则面（下次 gate 提议用户确认后入册）。

## 补充裁定：终态架构（同日深夜，用户「可以开卡」确认）

用户以主流 agent 对标（Claude Code/Codex/ZCode 级）追问「有快车道这种东西吗」——定案：**主流意图理解层 100% LLM，无词表绕道**；它们的确定性在执行层（工具）、审批层（permission gate/权限模式）、加速在模型侧（小模型/prompt caching）。Claude Code 的"确认卡"触发者是**模型工具调用**，非词表判定——同形不同权。

**修正**：本档早前「快道降级为缓存」建议作废，改为**退役路线**：秒出优势是自设的（对话等待行业已验证可接受）/两套大脑同步是持续税（222 同源锁定测试即实例）/快道存在即固化引力源。

**终态架构**：用户输入→LLM（全部，无词表前置）→模型自主（调工具/反问/提议）→治理门（权限模式+RiskConfirm）→确定性执行（VSP/CAS/读回）→模型继续或汇报。确定性层正位=执行+审批+兜底；词表退役四阶段：①闸开放+指引立（227，222 已立）②重验通（227 重验腿）③词表降级为 LLM 不可用兜底（后续卡）④退役或收缩为显式命令语法（后续卡）。

落地卡：227（闸 1 开放+重验）、228（观察面轨级插件披露——LLM 解析 plugin_id 前提，227 重验腿前置）。
