# 裁定：宏组件——用户越过姿态（2026-09-29，用户拍板）

- **裁定**：用户**可以**越过宏直接调插件参数（含打开插件编辑器）。不做锁——v1 无 editor 禁开、无参数软锁。
- **机制替代**（秩序不靠锁，靠组合语义与显式反馈）：
  1. delta 组合语义：宏写=在当前基线上加 Δ，用户手调=改基线，二者叠加共存（Bitwig modulator 先例；Ableton 绝对覆盖宏为反例）。
  2. 越过即自动重锚：绑定参数被手调后宏闭式重锚（origin_i := 实际值 − Δ_i），toast 通知+一键撤销，无对话框。
  3. 接管手势：在自有 UI 面直接抓取被绑定参数 = 自动解绑该参数（"你的手碰到哪，哪就归你"）。
  4. 宏徽标可见性：rack 中被绑定参数带宏徽标。
  5. "重新生成映射"入口：手调后语义偏移时，agent 基于新基线重新提议映射——用户手调成为 agent 的输入信号。
- **连带简化**：绑定管理态由三档（exclusive/shared/pinned）收敛为两形态（**可写绑定 / 仅显示绑定**），越过行为统一；裁决对话框降级为提交时 CAS 冲突的兜底路径。
- **论据**（备记录）：①哲学一致——本体系约束的从来是 agent（PCA/dose/CCB），不是用户；②行业一致——无主流 DAW 锁用户，automation 与手调共存为百年常态；③演示叙事——"永不锁死，随时越过且系统优雅适应"优于"会锁"。
- 出处：宏组件设计讨论第四轮（2026-09-29，决策会话）。其余已收敛设计面（DoF 抽象/通用控制车道/MacroLibrary/重锚算法/A 锚点）由 DESIGN 卡落契约。
- **补充（同日，用户认可的产品框架）**：宏=coarse 层（概览/语义命名/agent 生成/多参数协同，Δ 域以剂量域 ±10dB 可听原则封顶），效果器直调=fine 层（单参数外科手术/全范围）——两层字面对应 delta 价值模型 `最终值 = fine 基线 + coarse Δ`。越过不变量：宏旋钮含义=自身贡献 Δ，手调后依然为真，回宏即续调。效果边界诚实显示：余量耗尽告警 + 方向对冲可见（绑定三行：基线/Δ/实际值）。
