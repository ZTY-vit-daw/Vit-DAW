# Decision：范围操作路径裁定+自由态默认方向（2026-10-04，用户拍板）

来源：手测四号场用户方向输入 → REGION-OP-RECON-1 勘察（[RECON.md](../runs/REGION-OP-RECON-1/RECON.md)）→ 本日用户对话裁定。

## 裁定 1：执行路径=路线 a 物理拆（第一期）

- 范围操作（框选 clip 局部→拆出→单独调改）第一期走**物理拆**：拆分+子 clip 调改命令全链在位，唯一缺口=意图层不消费 `selected_clip_ranges`（RECON A5）。
- B1（组合式范围处理：范围渲染+接回时间线）：a 落地后的增强勘察卡，不现在立项。
- **B2（参数自动化限段处理）列入后续开发方向**（用户确认自动化包络线功能后续必开发）。B2 立项时一并设计其可视化：主场在时间线（clip/轨道上包络段——效果器挂 clip 则包络画在 clip 上，"这段才生效"直接可见）；机架做状态面（插件条限段时间界徽章+跳转时间线）；辖区 rack face 补"限段处理"条目（note 可答）。a 与 B2 长期共存：a=显式结构（机架可见、agent 直接操作对象）；B2=隐式参数（时间线可见、机架只见标记，可表达连续渐变——拆分表达不了的形态）。
- **B2 多段设计（2026-10-04 晚用户问询补）**：同一插件不同时间段不同参数=**单实例单包络多段**（包络=参数-时间函数，A 段 60%/B 段 35%=同曲线两段台阶），零新增实例；机架徽章「×N 段」+段列表（值各异）。agent 指令形态=包络关键点追加（非挂新插件），治理仍单变更。**双实例仅三边界**：①两段时间重叠且参数需求冲突（同一时刻参数只能一个值，物理不可能单实例）；②处理链顺序需求不同；③并行/send 结构不同——此类属结构需求，双实例各自带徽章天然可辨。
- **B2 链序分段设计（2026-10-04 晚续）**：同轨道不同时间段不同链序——行业无第一公民设计（传统=拆分或 bypass 杂技；唯一近似=Ableton Rack chain selector，乐器机架特化非混音链概念）。分层：**短期=双链+链级限段徽章**（自动化链启用/bypass，纯参数层复用 B2 包络，治理单变更；缺点 CPU 双链+bypass 交叉点待实锚）；**长期=链布局车道**（轨道处理链布局时间分段=产品级抽象，时间线结构车道标注每段链序，内部可仍双链切换，agent 语义"段落→链布局"）——远期登记。机架可视化四元素：链布局缩影条/播放头同步链视图（链区随播头换序+段标签）/时间线链布局车道/双链并存灰显（结构可见性原则）。
- **链自动化概念定稿（2026-10-04 晚三续，用户问询"链自动变化加载的插件和顺序"）**：①**首创边界校准（答辩红线）**——效果器**参数**自动化传统 DAW 有（plugin parameter automation 标准功能）；空白在**加载/链成员/链序作为自动化对象**（自动化对象扩展到结构层）——此表述为准；②**概念校准**——参数=连续量适合曲线；链成员/序=离散状态，天然形态=**分段轨道（离散事件轨）非曲线**（MIDI 先例：CC=曲线，Program Change=事件轨；链布局轨=效果链的 Program Change 轨，切换点=结构变更宏）；③**行业先例**——MIDI Program Change（时间点切换整组音色/预设）+数字调音台场景快照（时间点召回整组状态）证明"时间驱动宏切换"成熟，缺第一公民 UI；④**实现立场**——不做实时自由动态链（无缝/快照/CPU 三难点），做**链布局车道+预加载调度**（段边界前 N 秒预实例化下一段链+边界交叉淡变，把实时不可能变调度可解；每段布局自带参数集=快照免费）；⑤治理——链布局变更=结构 mutation，与拆分同口径（D1 单变更/轮或确认制），与两轮制协议同族；agent 可引用链预设宏（"用上次那条 B 链"）。

## 裁定 2：自由态为 Vit agent 默认工作流方向（用户方向输入）

- 演进方向：灵活上下文+agent 自主循环承接大工程，**替代固定编排**；自由态逐步成为 goal 执行的默认形态。
- 边界保留：D1"单轮一次前向变更"是**证据纪律**不是编排死板——自由态默认化不放开每轮变更数。拆掉的是固定步骤，保留的是每轮单变量归因。

## 裁定 3：自由态范围操作治理形态=两轮制（**仅 a/B1 路径**，非通用协议）

- 节奏由路径变更结构决定（用户澄清 2026-10-04）：a/B1=拆分+调改两次变更→两轮制；**B2=写包络单次变更→单轮原生合规，不套两轮制**。B2 治理维度反而最干净（单变更/不动结构/撤销=删包络），是 B2 将来立项的加分项，与工程维度大劣势并存。
- 轮 1 拆分（前向变更=split，post 取证=结构正确+听感基线，settle）→ 轮 2 调改（treatment=A/B/参数变更，判定 settle）。规则零改动。
- "拆分定性为准备操作"**不采纳**（改治理语义、削弱单变更不变量）；"前置拆分"（实验外确认拆分）作为退化形态自然共存，不需裁定。
