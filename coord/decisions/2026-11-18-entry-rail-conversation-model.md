# 2026-11-18（晚）入口常驻左栏与“对话流”交互模型（用户确认）

## 结论

- 用户确认走 B 方向：窗口级**常驻左栏**（启动页=工程列表，工程页=对话流列表），先 B1 结构、B2a 当前工作树内对话流、B2b 跨工作树。
- **唯一事务单位 = 对话流**（工作树 + 分支/节点）；工作树只是左栏分组语义，不是独立动作。
- 浏览与切换解耦：
  - 左栏点击任意非当前对话流 = **只读预览**；不调 history checkout、不 open_project、不重载 DAW；输入框加蒙版禁用。
  - 动作卡随上下文：
    - 当前工作树其它分支 → 【继续此对话】（现有 `version.node_checkout`/`version.checkout`，单次工程重载）；
    - 其它工作树的对话流 → 【打开此工作树并继续此对话】（打开工程副本 + 切到该对话节点）。
  - 不设独立“打开此工作树”动作；工作树通过“继续其对话流”进入。
- 用户同意新增 **agent 侧组合工具**（暂名 `version.conversation_open`，最终名以实现卡为准）：
  1) 校验目标工作树/分支/节点；turn 运行中禁止；当前工程未保存改动走既有 autosave/治理语义；
  2) 在目标工作树副本内物化目标 commit、更新 active worktree/branch/node（纯文件操作）；
  3) **最后只做一次** `withProjectReload` → 内核 `open_project` 目标工程，DAW GUI 只切换一次。
  - 失败语义：第 3 步之前失败 → 当前工程不受影响；第 3 步失败 → 显式失败态 + 重试/返回，不静默。
- 新建对话：当前工作树、当前分支、**当前活动节点**分叉出新对话流，创建后自动成为活跃流（避免双重重载；若必须重载则复用同一组合语义）。
- 收展/动效：左栏 280px、180ms 收展；B2 内容切换 180–240ms crossfade/slide；遵守 reduced-motion；不做跨窗联动（沿用 2026-11-17 裁定）。
