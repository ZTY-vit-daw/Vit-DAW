# 2026-11-18 子代理复用与 token 经济规则（长期）

- 裁定人：用户（2026-11-18 晚）；执行：PC 主管决策流。目标：把“决策会话上下文”当稀缺资源，减少一次性子代理和长回执。

## R1 子代理复用优先（本轮最重要）

1. **一条开发线一个常驻执行子代理**：窗口/对话流线、乐局 Go 线、评分/真栈线、材料线各自固定 owner；同线新卡用 `send_message` 续用原 agent+worktree，不为一卡新建一个 agent。
2. 只有以下情形新建子代理：文件域/技术栈完全不同；原 agent 已阻塞或产线终止；需要真正并行且文件域不相交。
3. 小修/连续调参（如动效时长 429→430→431）应合并给同一 agent 处理，必要时直接批量给多步指令，不逐卡重开。
4. 每次发卡/完结更新 `coord/agents/ROSTER.md`（owner 名、产线、worktree/分支、最近任务、状态）；主管先从名册选复用对象。
5. 子代理在本会话内 inactive 仍可 `send_message` 继续；跨会话名册只作参考，新会话可按同一 owner 命名新建，但应继承卡/证据上下文而非重述全史。

## R2 会话层：短会话 + 一页交接

- 按开发面拆会话（窗口/对话流/评分/乐局/论文等），不把整晚聊天带入次日；
- 每个 gate 更新 `coord/decisions/NEXT-SESSION-BRIEF.md`：main/dist、已验收卡、待办前三、栈状态、关键文件锚点；
- 新会话启动只读 NEXT-SESSION-BRIEF + POOL-INDEX + 相关卡/裁定，不重读历史、不重读全仓文档。

## R3 子代理回执契约（省主管 token）

- 完整日志、diff、截图、断言明细写 `coord/runs/`；聊天回执 **≤15 行**，固定字段：commit、命令+exit、文件数、断言/测试数、风险边界、3 个工件路径；
- 禁止把完整日志/大段 diff 贴进聊天；主管需要时按路径读摘要；
- 子代理必须在卡面/回执写明“零真栈/真栈”“未做边界”，不写泛泛总结。

## R4 复核分层

- 每张实现卡可配一个只读复核子代理输出“风险清单 + 主管需看的 1–2 个文件”；
- 主管只读裁定摘要+抽查高风险点，不逐行读全部 diff；复核结论落 `coord/rulings/`。

## R5 测试与工具输出经济

- 主管侧只跑定向测试（单包/单文件）与必要 smoke；全量 suite 由执行子代理或收尾批次跑；
- 命令输出用 tail/count/exit，不拉全量日志；长任务后台 job，只在真正阻塞时 wait；
- 渲染/真栈只读 summary/失败断言，原始工件留盘。

## R6 模型路由与并行

- 机械实现/重复跑测用 Flash 档；设计、架构、疑难裁定用较高档模型；不让高档模型重读大段历史；
- 并行仅用于文件域不相交任务；共享文件域的卡串行给同一 owner。

## R7 聊天/决策层

- 状态更新用表格/一句话，不重复已确认内容；
- 小修合并成一张卡一次交付，减少“回执→修→再回执”轮次；
- 设计讨论一次给选项与推荐；用户确认后落卡，不复述全史。

## 生效

- 本规则与 AGENTS.md §0 指针、`coord/agents/ROSTER.md`、`NEXT-SESSION-BRIEF.md` 同轮生效；下次会话首排按此执行。
