# 裁定：手测里程碑改判=AI-first 启动面；乐局线后置（2026-11-09，用户定向）

- 裁定人：用户（2026-11-09 原话意旨：「乐局线后置，它一定是依赖于编曲和生成能力落地后再进行编排设计的，并且现在有了新的启动面设计，那就说明这次手测的里程碑应该是这个启动面，而不是乐局本身」）

## 定调

1. **本次手测里程碑=AI-first 启动面**：手测 v2 的验收对象=启动面全旅程（启动台对话→白话/点选开工程→治理确认→进工程→浮动窗桥接播报→工程内继续对话）——即 339（LAUNCHER-SMOKE-1）真栈烟测通过后的用户 GUI 手测（原"手测 v2.5"升格为手测 v2）。
2. **乐局线整体后置**：乐局的编排设计依赖编曲+生成能力落地——乐局线（283 注册链⑤、EDU 待发卡、乐局手测旅程 A）全部挂起候编曲/生成线推进；已合入的乐局零件（276-282/314-316）留在 main（产品改进不受影响），乐局手测（旅程 A）取消候乐局线重启。
3. **优先级反转**：启动面（进行中）→ **编曲线**（273 验证腿+ARR 待发卡上调）→ **生成线**（285/GENSHELL 等）→ 乐局编排设计（重启时点候编曲/生成落地）。
4. **展演叙事修订**：12 月展演=启动即对话（录播第一镜）+ 工程内体验（混音裸控演示等既有证成内容）+ 生成「局外成品」素材；乐局素材候乐局线重启后补录或不进本次展演。
