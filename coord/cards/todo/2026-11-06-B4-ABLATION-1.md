## 背景

B4=低频关系/低频遮蔽（F 态）：固定面=`agent/internal/chat/capability_owner.go` 词表（低频关系/低频遮蔽词组）+语义守卫（普通 EQ 命令不进 B4，仅显式 marker）+canary dispatch `handleLowEndRelationRuntimeCanary`（v0 优先观察建议）。257 §五：复用面最多——观察工具✓（frequency_relationship/masking view+mix.derive）+EQ 闭环 harness 形态✓（ReAct 骨架 eq_plan 指引：频点/增益/Q 由模型声学判断）；**缺**：低频遮蔽判据指引（kick/bass 关系语义）。257 时 b13b 腿未跑（预算节制），本卡 ablation run 首跑该场景。

## 目标

1. **拆减开关**（263 同款模式，生产面 ≤20 行）：B4 族词表短路+canary dispatch 该分支禁用的 test-only 注入钩（env，默认 unset=生产行为字节不变；建议复用/泛化 VIT_AUTOMATION_INTENT_ABLATION 模式或新 env，执行侧定但须默认关字节不变+配对单测三态）；
2. **ablation run**（真栈单 run）：钩启用下跑 b13b masking frontier 场景话术族（样本数按脚本现有组配置，预期 5 样本级）；§8 跑前口径成文（≈¥2-4 单 run 无重跑，全 LLM 化调用多于词法形态）；
3. **判定（两分支均合法，263 先例）**：①工具链走通（tool_chain_ok/boundary_ok 计 successes，≥4/5）→B4 判 **A 态候选**（harness 自主复现成立，附证据）；②semantic_entry/守卫拦截（251 形态 conf<0.50 或守卫 fail）→按 263 裁定②同款**归类「入口识别薄层」维持 F/H**，如实记录拦截面（不判失败、不硬修凑过）；
4. 验收=开关默认 unset 既有测试零回退（go build+chat/agentloop 聚焦）+ablation run 判定面落档（coord/reports/）。
