# SCORE-TRACK-BIND-1：谱面轨道绑定+双模式（选择器/跟随/clip 小条/草稿）

- 发卡：主管 2026-11-17 凌晨（[裁定档](../../decisions/2026-11-17-window-and-score-design-ruling.md) §二；用户痛点=「常驻 clip 输入窗口不合理，用户不知道自己在编辑谁」）
- 池序 392；P1；依赖=374 谱面已合入+382 入口/错误边界已合入；真栈腿候栈位
- 目标：
  1. **轨道选择器（主模式 UI）**：谱面左侧轨道列表（选中高亮=显式「正在编辑谁」）；选轨→加载该轨 clip→五线谱显示+编辑（apply 写回选中 clip，374 读写回链复用）。
  2. **GUI 跟随（辅入口）**：DAW 主区点轨道→谱面选择器同步跟随（两入口一状态；事件链=轨道选择披露面，领取时锚定现有轨道选择事件，无则最小增补）。
  3. **clip 时间线小条**：轨内多 clip 横向缩略时间轴，点选编辑段（主管推荐档；实现中发现与谱面布局冲突可改拼接显示，卡面裁量）。
  4. **草稿模式**：谱面「新建草稿」不绑轨→编辑→生成 **clip 资产存工程包内 clip 库**（不默认落位）→对话指令转正（「把刚才那段放到旋律轨开头」→装载到轨）；资产清单/转正链的 agent 面语义最小区间。
  5. 回归+断言：轨道绑定状态显式断言（渲染面）+草稿生成/转正真栈腿+J1-J3 不回退。
- 边界：不动 374 谱面内核组件本体（编排层做）；草稿资产格式取工程包既有 clip 语义，不发明新格式；music_score 对话流控件不在本卡（阶段 2）。
- 文件域：`agent/webui/src/workbench/`+`scoreworkbench/`+轨道选择事件链（agent 侧如需）+`coord/runs/SCORE-TRACK-BIND-1/`。
- 验收：真栈腿 exit 0（选轨→编辑→apply 回读+草稿→转正落轨）+渲染断言+用户手测节点（「明确知道在编辑谁」+写新内容不落位可调用）。
