- 优先级 / 预估 / 依赖：P1 / 0.4 天 / L2-1-TIM-1 已验收合入（边界声明两项归本卡：AssertWarnLogger 接线+监督报警真栈断言）；设计文档 §4.2 烟测草案为规格
- 模型分级：L2 / GLM 亲自或强督导（harness 接线小改+真栈操作）
- **执行侧（PC 会话；§9 真栈单会话所有权——领取前确认无其他栈运行）**
- 目标：
  1. **接线（实现小改）**：`tim.AssertWarnLogger` 注入钩子接到 harness 的 logx 实例——WARN 行格式按设计 §1.4 惯例 `[tim.assert] key=value`（对齐 cont_stall 等既有前缀过滤断言模式）；默认 nil 静默语义保持（单测断言注入与静默两态）；文件域 agent/internal/harness+tim 接线点，红绿先行（注入后 WARN 行出现的单测）。
  2. **真栈烟测（设计 §4.2）**：复用现有 ps1 体系按同模式新增（或扩展 dev_agent_smoke 参数）：真实三件套上对样例工程触发 `mix_request_observation` → 断言 ①mix_read `observation.tim_projection` JSON 的 `assertions[]` 存在且每项三态合法（pass/fail/not_evaluable）②fixture 构造一个触发项（近满幅轨触发 AS-PEAK 或 AS-SIG P2——素材可用 temp 生成或既有样例工程轨）→ 预期 fail 码出现在 assertions+risk_summary ③agent 日志差分出现 `[tim.assert]` WARN 行 ④**脚本 exit 0=PASS**。
  3. 回执：接线红绿+烟测完整命令/退出码/run ID/HEAD/工件（§9 真栈回执契约全项）。
- 约束：接线零行为扩散（仅日志面）；烟测脚本进 scripts/ 体系（ps1，Windows 形态；mac 侧复跑需要时按 _mac 同模式翻译另办）；新 run 目录不覆盖。
- 验收：接线红绿+真栈烟测 exit 0（四断言组全过）
- 停止条件：真栈上 assertions 块为空/缺失（说明装配链未触发）→ 取证上交（不修装配链——域外）；两次同形态确定性失败 → 停止重跑取证
