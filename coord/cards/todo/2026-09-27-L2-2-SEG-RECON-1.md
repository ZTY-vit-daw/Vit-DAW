- 优先级 / 预估 / 依赖：P1 / 0.5 天 / 路线图 D10+L2-2 段（AGENTIC-OBSERVATION 蓝图）；实现卡（L2-2-SEG-1）依赖本卡
- 模型分级：L1 / flash 可接（纯只读勘察+报告，零代码改动）
- **执行侧（PC 会话）**
- 背景：路线图 D10 段落投影=发现与命名分离——发现层用确定性 DSP（self-similarity matrix 重复性 / novelty curve 能量谱变化点 / onset 密度），边界是可复核事实；关键验收"边界检测可复核（确定性重放一致）"。本卡盘清三算法在现有数据面上的落点。
- 目标：
  1. **现有 DSP/音频分析存量盘点**：agent 侧（audioclosure/probeaudio/acousticpackage/mom 的频谱与能量计算——频段能量/RMS/波形包络等，文件:行）+ 内核侧（VitApp 的 baker 族——WaveformEnvelopeBaker/TiledSpectrogramBaker 等，它们产出什么粒度的特征、落盘格式、采样点级访问能力）。逐一记录：特征类型、窗口/粒度、数据去向。
  2. **三算法×数据源可行性矩阵**：self-similarity（需要帧特征序列×自相关）、novelty（需要帧间距离/能量差分）、onset 密度（需要瞬态/短窗能量）——各自对照现有数据源（stems wav 原始数据、render 结果、TOM 波形特征、baker 瓦片）判断：现成可用 / 需补计算（在哪个层面补） / 缺数据源。
  3. **计算位置评估**：内核 C++（实时性/持久层）vs agent Go（离线分析/投影层）vs 两者协作——按"确定性重放一致"的验收要求评估（哪个位置能保证同一输入重算同一边界）。
  4. **段落/分段概念存量**：工程内已存在的 section/marker/段落概念（内核 marker/arranger 轨、TOM 投影聚合粒度轴、clip 结构）——发现层边界与它们的衔接点；D10"中性 ID S1…Sn"的承载位置候选。
  5. 报告落 `coord/runs/L2-2-SEG-RECON-1/SEGMENT_DSP_INVENTORY.md`（存量清单+矩阵+位置评估+缺口清单）。
- 约束：零代码改动；锚点带文件:行；算法可行性判断必须落到"具体哪个现有函数/字段能喂它"，不得停留在概念层。
- 验收：①存量盘点覆盖 agent+内核两侧 ≥8 个分析能力 ②三算法矩阵每格有具体数据源判定 ③计算位置评估含确定性论证 ④段落概念存量 ≥2 个衔接点 ⑤报告入库
- 停止条件：某算法在现有数据面完全无落点 → 如实记"缺数据源"+缺口清单上交，不硬凑可行性
