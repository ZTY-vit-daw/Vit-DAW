## 目标

1. **「＋新建」按钮=直接新建+自动进工程**：不经对话问询——点击即建（缺省名候 363 名实相符，暂用时间戳/草稿名）并自动进入工程面；对话流窗口切换为工程内形态。
2. **对话流新建/打开意图自动执行**：launcher 确定性路由命中新建/打开→directive 自动经桥执行（移除「让 Vit 新建/打开」手动按钮等待；烟测装置的 auto-execute 语义转正为生产行为）；治理三键卡按 337 语义仅在需要时出现。呈现区分：「Vit 正在执行→已进入工程」回执 vs 确定性问答；用户不再看到「问了但没做」的断链体验（取证：21:19:03 预设应答+directive 悬置）。
3. **启动页阶段 agent 无工程上下文**：boot 草稿（SHELL-4 引入）不得作为 agent workspace/对话上下文激活（取证：agent_last.log `workspace activated …Unsaved.vit`）——agent 位置=「启动页」，上下文零工程范围；进入/新建工程后才绑定工程（对话流跨卷桥接 338 语义保留）。实现方向候领取锚定：内核随窗在线保留（SHELL-4 不回退），agent 侧 workspace 激活延迟到真实进工程，或 boot 草稿对 agent 上下文不可见。
4. **回归守卫**：launcher 阶段对话上下文无工程绑定的断言（单测+烟测腿）；进工程 surface 切换+列表收起渲染断言（与 365 分工：365 做 fixture 面，本卡真栈腿）。

## 验收标准

- 真栈烟测：按钮直建腿+对话意图自动执行腿+启动台无 workspace 绑定断言（日志级）3/3 轮；三门不回退；
- 用户复测：点新建即进工程；对话说「新建工程」即执行不再问询循环；启动台对话不带工程上下文。
