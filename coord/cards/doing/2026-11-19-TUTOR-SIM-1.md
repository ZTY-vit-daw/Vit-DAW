# TUTOR-SIM-1：三步导师循环实验（自动开场 + 服务端验证）

- 池序 435；P0；PC；发卡=lead（2026-11-19 22:10）；派发确认=**用户「没问题，可以进行」**；验收负责人=lead。
- 目标：验证乐局导师循环的最小闭环：打开实验工程→自动开场（无命令词）→LLM 进入 YAML 人设→按当前步要求用户输入→**服务端精确验证**→错不推进、对推进→三步完成。无控件/谱面/音频，本轮不做。
- 实验 YAML（独立实验 schema，不动冻结 production design.v1）：
  - schema_version: vit.tutor_sim.v0；id: tutor-sim-3step；persona 文本。
  - steps：3 步；每步 ask/expect/retry/pass；expect 依次 "7"/"42"/"123"；trim 后精确匹配。
- 服务端 API 契约（UI 自动开场留 TUTOR-SIM-2）：
  - POST /agent/tutor/start {conversation_id?, project_path?}：从当前工程（或 project_path）读 .vit_agent/tutor_sim.yaml；无则 {status:"unavailable"}；有则创建内存会话、调用 flash LLM 生成开场（人设+第1步），返回 conversation_id/step_index/step_total/step_id/reply。
  - GET /agent/tutor/status?conversation_id=：当前步/是否完成。
  - POST /agent/chat：若 conversation_id 命中 tutor 会话，走 tutor loop：取用户文本 → trim/expect 判定 → fail 不推进并把结果给 LLM 重试引导；pass 推进并把下一 step 给 LLM；返回 workflow="tutor_sim" + workflow_data{step_index,step_total,step_id,passed,completed} + reply + stop_reason；**不得落入普通 agent loop**，不得自宣通过。
- 实验工程：一个空白工程 + 项目旁 .vit_agent/tutor_sim.yaml；提供 headless smoke 脚本；不要求设计源导入/legame 编译。
- 文件域：agent/internal/chat/tutor_sim.go（+test）、agent/internal/tutorsim（如需解析包）、coord/experiments/tutor-sim-1/、scripts/run_tutor_sim_smoke.ps1；不改 UI/冻结 design schema/其他产品面。
- 验收：Go 单测（YAML 解析/三步状态机/错不推进/LLM 假客户端）；headless 真栈脚本（lead 跑）：start 无命令、LLM 人设开场、输入 7/42/123 推进、错输入不推进、完成后停止、零命令词；真实 LLM 调用失败分类记录。
- 停止：若服务端实现必须改 UI/冻结 schema/普通 chat 主链，停手上报，不硬塞。
