## 目标

产出 `docs/PLUGIN_MEMORY_SCHEMA_V1.md`（新增），定义「插件域客观经验 memory」的 entry schema 与 advisory 策略。**只做域内规格与策略，不实现存储/检索/巩固**——机制层归 `AGENTIC_OBSERVATION_ROADMAP_2026-09-25.md` D14 Memory 系统。

必须覆盖：

1. **定位与键**：属 D14 三种记忆的「客观经验」类；聚合键=环境（机器 + 插件 identity/version/format + 参数面指纹），指纹失配 → 降权待复验，不跨设备同步；用户偏好与工程事实分别走人/工程键，不在本 schema 混用。
2. **条目类型**：`semantic_hint`（模糊参数名的可能含义）/ `gotcha` / `write_order_precondition` / `user_approved_setting`（仅客观可复核的设置事实，不承载偏好）/ `ambiguity_resolution` / `unsupported_boundary`；逐类列出允许字段与禁止内容。
3. **字段**：`schema_version`、`memory.entry` ref（对齐 REF_SCHEMA §6 `memory.entry` / `memory.distilled` 命名空间）、`trust`（observed / user-confirmed / agent-inferred / conformed / unsupported）、`confidence`、`evidence_count`、`evidence_refs`、`context_tags`、`created_at/updated_at/expires_at`、`plugin_identity + surface_fingerprint`、`content`、`limitations`。
4. **写入策略**：capture 触发（用户纠正、失败重试、实测 gotcha、用户认可设置）、谁可写、矛盾保留（不覆盖、带上下文并存）、过期/合并字段（执行细节留 D14）。
5. **消费契约（非权威）**：只进 planner/LLM 上下文或只读工具；**不是执行权威、不是参数映射来源、不是 credential、不产生可调度路径**；typed executor 必须 fresh inspect 重新推导；冲突时 live 证据优先；附「notes 不得新增可调用控制路径」的测试断言建议（供后续实现卡）。
6. **样例**：Pro-Q 3 / Pro-C 2 / Valhalla Plate（或同族 reverb）各 ≥2 条，标 evidence_refs；覆盖写序、`Mix` 0–200%、非有限端点、通道/立体声联动等真实 gotcha 至少各一例。
7. **与既有资产的关系**：明确不复用、不复活 VPS/Profile/SPAL 执行权威（`docs/SPAL_VPS_RETIREMENT_ADR.md`）；说明与 `docs/COMPRESSOR_REFERENCE_PRO_C_2.md`（human reference exemplar，非运行时）的区别；不写任何可执行参数映射/alias/credential。
8. **D14 接入点**：raw append-only stream vs distilled markdown 的职责；查询/consolidate/画像由 D14 提供；本卡只定义域内 schema/policy 与未来接入约定。
