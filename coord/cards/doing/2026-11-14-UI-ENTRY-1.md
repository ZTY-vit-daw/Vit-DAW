## 目标

1. **启动窗路由**：autoload 模式下 autoload 窗启动加载 `?surface=launcher`（启动台），非 `/app/` 主对话面；agent 未就绪期显示装载/等待态（347 LoadingGate 模式可参）。
2. **Godot 主窗启动隐藏**：autoload 模式且 React 窗成功建立时，Godot 主窗在启动阶段不显示（隐藏时序注意：需在首帧可见前决策，避免闪现；若 Godot 侧无法完全防闪现，记录残余闪现并最小化）。
3. **进工程展开**：348 桥 open 链成功 → Godot 主窗显示（DAW 展开动画由宿主约束，不伪造）；React 窗**同窗不重载**切到 project surface（343 不变量 navigate_count 不增——surface 切换走 React 内部路由/postMessage，**不得整页导航**）。
4. **回退链**：React 窗建立失败/agent 超时/WebView2 不可用 → Godot 主窗显示启动页（现 start_page 兜底链复用）；用户在启动台关闭 React 窗=退出应用还是回退 Godot 页？——**按回退处理**（关窗≠退出产品），如实现代价异常可降级为退出并记录。
5. **legacy 不变**：默认 flag 下行为与现状完全一致（含双窗形态——legacy 本就 Godot 单门面）。
