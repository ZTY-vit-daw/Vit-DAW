# 教材遵循度与可试听谱例材料库（修订稿）

## 1. 对第一稿的判断

第一稿依据了单元知识和三项实践，但还不能称为完整落实教材教学内容：知识与原谱的逐项绑定不够，实际可听材料仅预留《小草》《怀念战友》，四种旋律线又允许用自制示范，容易让课堂变成“借教材题目做共创”。本次把**教材知识—原例—观察/讲解—学生实践—证据**逐项补齐。

沿用教材“基本知识→创作示例→编创实践”的内容关系；任务中可以交织讲解和动手，不要求逐页读完。先节奏后旋律、Tap、版本比较、YuE2 成曲是本项目交互/拓展，不冒称教材原文安排。

## 2. 内容对照与材料绑定

所有页码是书内页，PDF 对应加5；书内16-30页原图已缓存。

| 教材内容 | 原例与页码 | 课程内必须发生的内容 | 材料 ID |

| 同音反复 | 《我向党来唱支歌》17页 | 看/听教材标注同音段，再注意节奏如何改变表达 | `pitch-repeat` |
| 上行级进 | 《哆来咪》18页 | 定位上行音级，并解释听感；保留五声音阶例外说明 | `pitch-step-up` |
| 下行级进 | 《小白菜》19页 | 与上行片段对照，避免把方向与情绪机械一一绑定 | `pitch-step-down` |

这份主材料库拟含22个材料条目：5个音高进行、4个节奏、4个轮廓、2个综合示例、5个发展示例、2个《三十里铺》参照。它们是小段材料，不是22套新控件，也不要求把22段连续播放一遍。按知识点需要加载并记录观察/理解证据，已有掌握证据的部分可缩短。

其他原例《烈士墓前》《驿动的心》《鲁冰花》《怒吼吧，黄河》《嘉陵江上》《五彩缤纷》仍在原页中可查，可后续加入替代/对照，不把转写全单元每一首歌设为首包前置。

## 3. 材料应怎样放入工程包

建议包内原料结构：

```text
assets/
  catalog.yaml          # ID、出处、用途、文件、截取范围、核验状态
  midi/                 # 按原谱转写的短片段
  score/                # 校订的 MusicXML/ABC，后续准备；原页保留在source/pages
  audio/                # 可选：固定音源渲染的预览；默认由内核实时播放 MIDI（2026-11-12 更正）
```

同一材料 ID 关联原页、转写谱/MIDI、可播放预览、小节/拍坐标和知识标记。模型发出“加载 pitch-step-up 的标注段”，宿主定位资源并显示/播放，模型不临时重写谱例。谱面点击、音符高亮和循环区引用同一数据。

MIDI可现场加载到参考/示范轨，用当前音源试听和观察音符；常用片段也可预渲染音频供轻量播放器直接播。两者指向同一转写版本，不能播放A版本音频却显示B版本谱。实际教学参考材料与学生答题轨分开保存。

这里只是在讲解中需要时加载，不预先把所有例子铺满工程轨道。包随工程导入/移动时解析相对路径，不依赖原下载目录；当前设计目录并非已经安装的工程包。

## 4. 转录材料和原录音的不同用途

用户提出“乐曲采样”，本轮优先做的是**按教材谱例转写 MIDI，再用音源播放**。它适合准确展示音高、节奏与轮廓，不需要截取完整商业录音来完成这些操作。

教材创作示例还讨论歌词、情绪、风格和手鼓节奏。纯钢琴 MIDI 可呈现部分组织，不能代替真实演唱/配器语境。若该环节需要听到真实演唱与风格，可另外准备对应短录音；原录音与教学 MIDI 独立标记，不把合成演奏冒称原唱。原词/背景和教材分析应仍可查看。

## 5. 每条可用材料的核验

1. 明确截取的是哪页、哪条谱例、哪几个实际小节；弱起、连线、跨小节和多声部不要随手丢掉。
2. 对照原谱转写音高、节奏、休止、调号/拍号等。未给BPM/调号的地方，演示设定单独记录。
3. MIDI/记谱往返解析，核对逐音事件、总拍数和小节；节奏专用数据不冒充原旋律。
4. 用确定音源听核，校对高亮/循环与声音对应；未听核不要标为“已通过播放验收”。
5. 知识标记和使用说明应指向具体范围；模型解释引用这些标记和原文，避免凭文件名猜内容。

材料核验针对源样例；学生创作评议仍按开放题证据，不把与原曲音符一致当作练习答案。
