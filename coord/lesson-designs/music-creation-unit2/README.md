1. [教材内容摘要与题目依据](TEXTBOOK-NOTES.md)：单元知识、曲目、三项实践、准确页码和容易误读的地方。

3. [课程设计源 YAML](design.v1.yaml)：拟议 `vit.legame_design.v0`，供继续讨论/修改；**不是现有运行时可直接加载的 level.yaml**。
   配套 [教材遵循度与材料对照](TEXTBOOK-ALIGNMENT-AND-MATERIALS.md)、[谱例目录](assets/catalog.yaml)明确各概念使用哪段原例；当前22项规划中2项已生成MIDI，其余未伪装为已有。
4. [定向文本提取](source/unit2-extracted-text.md)：逐页原文文本；谱例应看同页图像。
5. [来源清单](source/manifest.json)、[逐页原始/清理文本 JSON](source/pages.json)、[全单元缩略图](source/unit2-contact-sheet.png)。
6. [两项精选符号材料](source/selected-symbolic-materials.json)：练习二原型动机的相对音级与节奏、《三十里铺》前两句的节奏转写。由此已生成两份 [MIDI及清单](assets/seed-midi-manifest.json)，尚未做实际音源听核，不代表全部谱例已转写。
7. [资料与设计核验结果](verification.json)：源文件/图像哈希、源格式引用、符号时值和未完成材料清单；不代表真实栈课程验收。
