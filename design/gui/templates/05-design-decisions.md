# 设计决策说明（模板 05 · 供复刻忠实还原）

> 配套：`templates/assets/traceui.css`（唯一样式事实源）+ 模板 01–04。
> 决策链完整记录见 `design/gui/direction-approved.md`（§5–§10）；实施差距与分卡见 `design/gui/IMPLEMENTATION_PLAN.md`。

## 1 · 配色系统

- **延续 webui 生效的 Mondrian Workbench v1 基因**（`styles.css` 第二段 `:root`，非软阴影基础层）：纸灰 #f4f4f1、墨 #111、蓝 #1557d6、黄 #ffd42a、红 #e63426、硬投影 `7px 7px 0 rgba(17,17,17,.12)`。理由：与现存功能页面协调（BRIEF §2），零迁移成本。
- **框体颜色契约（三层视觉语言，本轮核心决策）**：
  - 输入（用户消息）= **蓝底框**：#dbe6fc（--blue-inp）+ 2px 墨边，右对齐，max-width 86%。蓝色=用户/能动性，一眼区分"这是我说的话"。
  - 输出（确认卡/判定卡）= **白底框**：纯白 + 2px 墨边 + 硬投影 + 蓝底页签（settled 后页签转灰 #e4e8ee）。白色=Agent 交付的确定内容。
  - 轨迹（过程）= **无框**：透明底融于纸面，结构只靠节点。完成的事沉下去，待裁的事浮上来——"弱轨/强卡"层级。
- 语义色纪律：蓝=能动/进行，黄=信任锚与回滚，红=错误与拒绝，灰=沉淀/已消化。不混用。

## 2 · 字体与排版

- 中文 Microsoft YaHei（宿主栈）；动作名/时长/工程量= Consolas 系 mono——**工具语言用等宽**是轨迹可信感的来源（Codex/DSH 观感）。
- 行式轨迹排版（C 方向遗产）：每步一行 = 节点(8px) + mono 动作名 + 汉语 gloss + 右对齐 mono 时长；摘要短句第二行；细节白底细左线抽屉可展开。
- 字阶：正文 13 / 标题行 12.5–13 / 辅助 11.5 / mono 12.5 / 徽标 11。窄栏（360）不破版：按钮区固定两列、k 标签缩窄、气泡 94%。

## 3 · 间距与结构

- 对话流纵向 gap 12px；卡片自带 `margin:14px 0 4px` 给页签让位（页签突出卡顶 17px）。
- 轨迹块：收起=单行回执（图标+标题+副文+时长+chevron）；展开=`grid-template-rows 0fr→1fr` 过渡（.28s）；**输出完成后自动收起**（延迟一拍 ~900ms 让完成态可读）。
- 弹性宽列（用户定案）：面板宽 360–980 自适应，默认 720；内容不重排只舒展。

## 4 · 关键交互决策（按时间序）

1. **轨迹四态节点**：黑实心=完成；蓝实心=直接执行（完全档）；蓝环 spinner=进行中；灰空心=排队中；灰环呼吸=思考。无导轨线、无框（用户两次削减后的终态）。
2. **思考行**：live 块顶部，淡灰呼吸文字+块状游标，文案 ~2.8s 轮换；回合结束移除。
3. **收起回执**：完成态显示「✓ 标题 · N 步 + 关键发现 + 总时长」，点击重展开回看。
4. **完全档（full access）**：确认卡整层消失，链统一为观察→直接执行→渲染；变更步骤蓝节点+「完全档 · 直接执行」标，原确认卡的假设/预期折叠进步骤细节；判定卡成为唯一人裁点；「每步仍可回滚」副注常显。
5. **A/B 两裁决（用户 2026-09-03 定案，取代早期四裁决）**：「A 更好 · 回滚」「B 更好 · 保留」两按钮。后端映射：A→preference=a（rolled_back）、B→preference=b（improved）、直选隐含 heard=yes；「听不出/折中/另有想法」走卡面补充输入（free_text）。
6. **卡面补充输入（.c-ask）+ 免选路径**：每张待裁卡底部输入行；发送后内容入对话流、卡片沉淀灰条「已收到你的补充 · 卡面选项未采用」；无视卡面直接在底部输入框发消息同样让待裁卡沉淀「卡面选项未采用 · 你在对话中继续了」。语义：**选项是加速器不是门槛**。
7. **判定卡要素**：round 徽标（第 N/M 轮）、黄底回滚信任锚（视觉权重最高）、A/B 磁带行（快速切换对比+播放进度蓝染）、裁决后 settled 灰化。
8. **非回合活动线**：无框灰字细行（spinner/错误图标），只承载上传等非回合活动；回合内思考归轨迹块。
