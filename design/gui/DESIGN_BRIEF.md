# Vit-DAW · Agent GUI 设计交接书（DESIGN BRIEF v1.1）

> 交付对象：设计代理（DSH / opendesign 工作流）。本文档是设计模板的唯一需求事实源；
> 复刻实现将以本契约 + 模板为准。字段级 API 契约由 GUI-SURVEY1 勘察报告补充为 v2，
> 设计可先按 v1 开工，v2 只加字段不加交互面。
> 产品语言：中文界面。

## 0. 一句话背景

Vit-DAW 是一个 AI 混音助手产品。本次设计对象是 **Agent GUI**——Agent 的对话与交互面板（技术上是 `agent/webui` 这个 React 面板，通常经 CEF 以侧栏形式内嵌在 DAW 窗口内，也可在独立浏览器窗口打开）。

**形态硬约束：按"面板"设计，不是按"网站整页"设计。** 主形态 = DAW 内嵌侧栏（宽度可变，按 360–540px 窄栏为基准设计，需在 720px 展宽下不破版）；次形态 = 独立浏览器窗口（同构自适应）。用户的混音诉求在这条对话流里提出；Agent 观察工程、提出**有界的可逆试验步**（如"对人声轨 200-400Hz 做 −5dB 窄幅修正"），经用户确认后执行，用户试听 A/B 后裁决去留。

**DAW 本体（Godot 前端的轨道编辑器/调音台/路由等）零改动、零设计**——模板里不要出现任何 DAW 界面元素，面板就是全部画布。

## 1. 五个交互面（模板需逐个出）

### ① 确认卡（Agent 提议 → 人批准）
嵌在对话流中的卡片。必显：改动一句话（域+轨+剂量，如"对 vocals 轨做 static_eq：315Hz ±5dB"）、假设一句（Agent 为什么认为该改）、预期效果一句。动作：**批准 / 拒绝**。状态：待裁 / 已批准 / 已拒绝（已裁态要有视觉沉淀，不消失）。

### ② 判定卡（试听 A/B → 人裁决）——本产品的核心卡
嵌在对话流。必显：**A/B 两段音频播放器**（改动前/改动后，支持快速切换对比）、当前试验步摘要、**"这是试验步，可一键回滚"的醒目标识**、剩余轮次预算（如"第 1/3 轮"）。动作：**听得出·保留 / 听得出·更糟·回滚 / 听不出·下一轮加码 / 太过了·回退一半**。设计要求：判定卡与确认卡同构（同一设计语言的两兄弟：都是"Agent 动作 → 人来裁"）；"试验步可回滚"标识是产品信任的锚，视觉权重要够。

### ③ 权限开关（full access）
普通 / 完全 两档切换，当前档位状态清晰可见。普通档=每步都要人确认；完全档=Agent 连续执行（设计上要传达"更强 autonomy"的语义与边界感）。

### ④ 思考与执行呈现（替代现有大深色轨迹面板）
已定方向（用户 2026-08-26 裁定）：**淡灰色"正在思考…"动态文字 + 每步执行摘要短句流**。规格：思考中=一行淡灰动态文字（呼吸/游标动效）；每完成一步=一行短句摘要（如"观察完成：人声轨高频事件密度偏高"），可点击展开细节；不要大面积深色面板，不挤占对话流。

### ⑤ 对话流容器
以上卡片全部内嵌于对话流，按时间顺序沉淀；对话流是页面主体，任何面板不得挤占其宽度。

## 2. 全局设计要求

- **卡片同构**：①②同一设计语言；同为"裁决"语义的组件复用。
- **信任锚**：试验步可回滚、每步有界、人是最终裁决者——这三个语义要在卡片层面可感知。
- **节奏语义**：产品默认"先粗调后收敛"（首轮改动幅度大到普通人可听出，后续轮收敛）——判定卡的"听不出·下一轮加码"是常态路径不是错误路径，设计上不要把它做成消极态。
- 面板空间纪律：360px 窄栏下卡片不得溢出、A/B 播放器须可用、按钮区不得换行错位；720px 展宽只允许留白舒展不允许结构重排。
- 现有界面风格可参考 `agent/webui/src/`（复刻时保持与现存功能页面的协调即可，不要求逐像素延续）。

## 3. 输出要求（交付物）

1. **形态**：HTML/CSS 静态原型优先（可直接在浏览器打开预览）；若工具不支持，高清整屏图 + 组件级标注稿亦可，但需注明字号/间距/色值。
2. **清单**：主对话视图 ×1（含 ①②④⑤ 全部元素的状态组合：思考中/待确认/待判定/已裁决）+ ③ 的两种档位态 + ①② 各自的已裁沉淀态；组件级拆解页（按钮/播放器/状态徽标单独列出）。
3. **命名与存放**：交付至 `D:\Vit_DAW\design\gui\templates\`，每屏一文件，文件名用 `01-main-chat-thinking.html` 这类"序号-场景"式。
4. 附一页"设计决策说明"：配色/字体/间距系统的选择理由，供复刻时忠实还原。

## 4. 非目标（不要做）

- 不设计 DAW 的任何部分（轨道编辑器/调音台/剪辑视图/传输条——Godot 前端零改动，模板画布内不出现 DAW 元素）。
- 不改 agent 后端行为（本阶段纯视觉与交互层；数据字段已由工作流提供）。
- 不做多语言（中文单语）。
